# TAGLINE

使用 zsh 模式批量重命名文件

# TLDR

**将文件名从小写改为大写**

```zmv '(*)' '${(U)1}'```

**为所有文件添加前缀**

```zmv '(*)' 'prefix_$1'```

**更改文件扩展名**

```zmv '(*).txt' '$1.md'```

**以连续编号重命名**

```zmv -n '*.jpg' 'photo_$((++n)).jpg'```

**试运行（显示将会发生什么）**

```zmv -n '(*)' 'new_$1'```

**将文件移动到子目录**

```zmv '(*.txt)' 'subdir/$1'```

# SYNOPSIS

**zmv** [**-finqQsvwW**] [**-C**|**-L**|**-M**|**-p** _program_] [**--**] _srcpat_ _dest_

# PARAMETERS

**-n**
> 试运行，显示将要执行的操作

**-f**
> 强制覆盖，不做提示

**-i**
> 交互式，覆盖前提示

**-q**
> 安静模式，不报告错误

**-Q**
> 强制在模式上使用裸 glob 限定符

**-s**
> 创建符号链接而不是移动

**-v**
> 详细输出，打印每条命令

**-w**
> 从模式中提取通配符部分

**-W**
> 与 -w 相同，但进行模式替换

**-C**
> 复制而不是移动

**-L**
> 创建硬链接而不是移动

**-M**
> 移动（默认）

**-p** _program_
> 使用指定程序代替 mv

# DESCRIPTION

**zmv** 是一个 Zsh 内建函数，利用模式匹配和替换来批量重命名文件。对于复杂的重命名操作，它比基础的 mv 更强大。

源模式使用 Zsh 扩展 glob。圆括号分组会被捕获，并可在目标模式中以 **$1**、**$2** 等形式引用。Zsh 的参数展开修饰符可以对捕获的文本做变换。

常用修饰符：**${(U)1}** 转大写、**${(L)1}** 转小写、**${(C)1}** 首字母大写、**${1:t}** 取尾部（基本文件名）、**${1:h}** 取头部（目录）。

zmv 必须先加载：**autoload -U zmv**

# CAVEATS

zmv 是 Zsh 特有的。它在 bash 或其他 shell 中无法工作。

执行前务必先用 **-n**（试运行）验证操作。

模式使用 Zsh globbing，与正则表达式不同。启用 extended_glob（**setopt extended_glob**）可获得完整的模式支持。

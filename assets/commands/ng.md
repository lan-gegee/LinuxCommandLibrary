# TAGLINE

Angular CLI

# TLDR

**创建新项目**

```ng new [project-name]```

**运行应用**

```ng serve```

**构建应用**

```ng build```

**生成组件**

```ng generate component [name]```

**生成服务**

```ng generate service [name]```

**运行测试**

```ng test```

**运行 e2e 测试**

```ng e2e```

**添加库**

```ng add [package-name]```

# SYNOPSIS

**ng** [_command_] [_options_]

# PARAMETERS

_COMMAND_
> Angular CLI 命令。

**new** _NAME_
> 创建新项目。

**serve**
> 启动开发服务器。

**build**
> 构建项目。

**generate** _TYPE_ _NAME_
> 生成代码。

**test**
> 运行单元测试。

**--help**
> 显示帮助信息。

# DESCRIPTION

**ng** 是 Angular CLI，用于创建和管理 Angular 应用。

该工具负责搭建项目骨架，并处理构建、测试和部署。

# CAVEATS

需要 Node.js。基于 TypeScript。配置位于 angular.json。

# HISTORY

Angular CLI 由 **Google** 创建，为 Angular 框架开发提供配套工具。

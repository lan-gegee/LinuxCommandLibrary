# TAGLINE

解密 yadm 加密的文件

# TLDR

**解密文件**

```yadm decrypt```

**解密到指定位置**

```yadm decrypt -l```

# SYNOPSIS

**yadm** **decrypt** [_options_]

# PARAMETERS

**-l**
> 列出待解密的文件。

# DESCRIPTION

**yadm decrypt** 解密由 yadm encrypt 加密的文件。从加密归档中恢复敏感文件。需要 GPG 口令或密钥。

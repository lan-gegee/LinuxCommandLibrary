# TAGLINE

宏处理器

# TLDR

**处理文件**

```m4 [input.m4]```

**输出到文件**

```m4 [input.m4] > [output.txt]```

**定义宏**

```m4 -D [NAME=value] [input.m4]```

**指定包含目录**

```m4 -I [/path/to/includes] [input.m4]```

**为内置宏加前缀**

```m4 -P [input.m4]```

**调试输出**

```m4 -d [input.m4]```

# SYNOPSIS

**m4** [_options_] [_files_]

# PARAMETERS

_FILES_
> 要处理的输入文件。

**-D** _NAME=VALUE_
> 定义宏。

**-U** _NAME_
> 取消定义宏。

**-I** _DIR_
> 添加包含路径。

**-P**
> 为内置宏加上 m4_ 前缀。

**-d**
> 启用调试输出。

**--help**
> 显示帮助信息。

# DESCRIPTION

**m4** 是一个宏处理器。它展开文本文件中的宏以生成输出。

该工具用于预处理配置文件和源代码，也是 autoconf 的组成部分。

# CAVEATS

符合 POSIX 标准。引号规则可能比较难掌握。被 autoconf 大量使用。

# HISTORY

m4 于 20 世纪 70 年代在**贝尔实验室**开发。GNU 版本在最初的 POSIX 规范基础上进行了扩展。

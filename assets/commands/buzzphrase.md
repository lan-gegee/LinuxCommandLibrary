# TAGLINE

生成随机的企业流行语短语

# TLDR

**生成一个随机的流行语短语**

```buzzphrase```

**生成多个流行语短语**

```buzzphrase [5]```

# SYNOPSIS

**buzzphrase** [_count_]

# DESCRIPTION

**buzzphrase** 生成随机的企业流行语短语，将行话术语组合成听起来很正式却毫无意义的商业用语。可用于幽默、恶搞文档或测试文本输入框。

生成的短语从预定义的企业行话列表中组合形容词、动词和名词。

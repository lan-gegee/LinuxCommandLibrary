# TAGLINE

Calligra 套件中的电子表格应用

# TLDR

**启动 Calligra Sheets**

```calligrasheets```

**打开**电子表格文件

```calligrasheets [spreadsheet.ods]```

# SYNOPSIS

**calligrasheets** [_options_] [_file_]

# DESCRIPTION

**calligrasheets** 是 Calligra 办公套件中的电子表格应用。它支持公式、图表和数据分析功能，类似于 Microsoft Excel 或 LibreOffice Calc。

该应用使用 ODF（开放文档格式），并可导入/导出多种电子表格格式。

# INSTALL

```apt: sudo apt install calligrasheets```

```dnf: sudo dnf install calligra```

```pacman: sudo pacman -S calligra```

```apk: sudo apk add calligra```

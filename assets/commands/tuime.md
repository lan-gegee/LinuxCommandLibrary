# TAGLINE

多彩且可定制的 TUI 时钟

# TLDR

**显示默认时钟**

```tuime```

**自定义时间格式**

```tuime --format "[%H:%M:%S]"```

**自定义颜色和字体**

```tuime --color [red] --font [font-block]```

# SYNOPSIS

**tuime** [_options_]

# DESCRIPTION

**tuime** 是一个简单、多彩的终端 TUI 时钟。它支持可定制的时间格式、多种字体（block、simple、3D 等）、渐变颜色支持以及 UTC 偏移配置。

# HISTORY

**tuime** 由 **Nathan Dawit**（nthnd）创建，用 **Rust** 编写。

# INSTALL

```aur: yay -S tuime```

# TAGLINE

显示 TeX Live 软件包在仓库中的可用候选版本

# TLDR

**显示软件包候选版本**

```tlmgr candidates [package]```

# SYNOPSIS

**tlmgr candidates** _package_

# PARAMETERS

_package_
> 要查询的软件包名称。

# DESCRIPTION

**tlmgr candidates** 显示哪些仓库提供某个软件包。列出已配置仓库中可用的版本。TeX Live Manager 的组成部分，适用于多仓库环境。

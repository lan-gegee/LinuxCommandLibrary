# TAGLINE

X11 的平铺窗口管理器

# TLDR

**启动 i3**

```i3```

**使用自定义配置**

```i3 -c [~/.config/i3/config]```

**替换正在运行的实例**

```i3 --replace```

**以日志文件启动**

```i3 --shmlog-size=[10485760]```

**检查版本**

```i3 --version```

# SYNOPSIS

**i3** [_options_]

# PARAMETERS

**-c** _FILE_
> 配置文件。

**-a**
> 禁用自启动。

**--replace**
> 替换正在运行的窗口管理器。

**--shmlog-size** _SIZE_
> 共享内存日志大小。

**-V**
> 详细模式。

**--version**
> 显示版本。

**--help**
> 显示帮助信息。

# DESCRIPTION

**i3** 是 X11 的一款平铺窗口管理器。它以树形结构组织窗口，包含工作区、容器和布局。

该窗口管理器采用键盘驱动的导航和配置方式。它支持多显示器设置和高度的自定义。

# CAVEATS

仅支持 X11。Wayland 版本是 Sway。配置需要一定的学习成本。

# HISTORY

i3 由 **Michael Stapelberg** 于 **2009 年**创建，是一款注重简洁和文档的改良型平铺窗口管理器。

# TAGLINE

将支持 Angular schematics 的 npm 软件包添加到项目中

# TLDR

**将软件包添加到项目**

```ng add [package-name]```

**添加 Angular Material**

```ng add @angular/material```

**添加 PWA 支持**

```ng add @angular/pwa```

**跳过软件包安装**

```ng add [package] --skip-confirmation```

# SYNOPSIS

**ng** **add** _package_ [_options_]

# PARAMETERS

**--skip-confirmation**
> 跳过确认提示。

**--defaults**
> 使用默认选项。

**--registry** _url_
> 要使用的 npm 仓库。

# DESCRIPTION

**ng add** 将支持 Angular schematics 的 npm 软件包添加到项目中。它会自动运行安装和配置 schematics。属于 Angular CLI 的一部分。

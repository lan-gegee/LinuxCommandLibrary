# TAGLINE

显示 Toolbx 帮助信息

# TLDR

显示**手册**

```toolbox help```

**子命令**的帮助

```toolbox help [subcommand]```

# SYNOPSIS

**toolbox help** [_COMMAND_]

# PARAMETERS

**COMMAND**
> 要获取帮助的子命令

# DESCRIPTION

**toolbox help** 显示关于 Toolbx 及其子命令的帮助信息。不带参数时，显示通用手册；给出子命令名称时，则显示该特定命令的详细帮助。

# INSTALL

```apt: sudo apt install podman-toolbox```

```dnf: sudo dnf install toolbox```

```pacman: sudo pacman -S toolbox```

```zypper: sudo zypper install toolbox```

```nix: nix profile install nixpkgs#toolbox```

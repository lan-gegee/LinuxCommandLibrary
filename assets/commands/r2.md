# TAGLINE

逆向工程与二进制分析框架

# TLDR

**打开二进制文件进行分析**

```r2 [binary]```

**以写入模式打开**

```r2 -w [binary]```

**打开并执行分析**

```r2 -A [binary]```

**调试模式**

```r2 -d [binary]```

**打开远程文件**

```r2 [gdb://host:port]```

# SYNOPSIS

**r2** [_options_] [_file_]

# PARAMETERS

_FILE_
> 二进制文件。

**-A**
> 运行分析。

**-w**
> 写入模式。

**-d**
> 调试模式。

**-a** _ARCH_
> 架构。

**-b** _BITS_
> 位数（32/64）。

**-c** _CMD_
> 运行命令。

# DESCRIPTION

**r2**（radare2）是一款开源逆向工程框架，用于分析、反汇编、调试和修补二进制文件。它支持广泛的架构和文件格式，提供带有数百个命令的交互式命令行 Shell，可用于浏览代码、检查数据结构和执行取证分析。

该框架内置反汇编器、十六进制编辑器、调试器和脚本引擎。**-A** 标志会在加载时触发自动分析，识别函数、字符串和交叉引用；**-d** 则启用对运行中进程的实时调试。通过 GDB 等协议还支持远程分析，可连接嵌入式目标和虚拟机。其插件系统以及 Python、JavaScript 和 r2pipe 脚本接口使其可以扩展出自定义的分析工作流。

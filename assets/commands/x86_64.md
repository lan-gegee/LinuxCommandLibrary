# TAGLINE

以 x86_64 架构模式运行程序

# TLDR

此命令是 **setarch x86_64** 的别名。

**查看**原始命令的文档

```tldr setarch```

# SYNOPSIS

**x86_64** [_options_] [_program_ [_arguments_]]

# DESCRIPTION

**x86_64** 是指向 **setarch** 的符号链接，它以报告架构为 x86_64 的方式运行程序。等价于运行 **setarch x86_64**。

它通常用于 64 位系统上，以确保程序检测并以 64 位模式运行；不过在原生 x86_64 系统上，这通常已是默认行为。

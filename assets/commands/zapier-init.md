# TAGLINE

初始化新的 Zapier 集成项目

# TLDR

**初始化新集成**

```zapier init [path]```

**使用模板初始化**

```zapier init [path] --template [minimal]```

# SYNOPSIS

**zapier** **init** [_options_] _path_

# PARAMETERS

**--template** _name_
> 使用指定的模板。

# DESCRIPTION

**zapier init** 创建新的 Zapier 集成项目，用样板代码搭建项目结构。是用 CLI 开发 Zapier 集成的起点。

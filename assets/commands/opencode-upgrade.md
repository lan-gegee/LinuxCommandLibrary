# TAGLINE

将 OpenCode 更新到最新版本

# TLDR

**升级** OpenCode 到最新版本

```opencode upgrade```

# SYNOPSIS

**opencode upgrade**

# DESCRIPTION

**opencode upgrade** 将 OpenCode 安装更新到最新的可用版本。它会下载最新发布版并替换当前的二进制文件，同时保留现有的配置和会话数据。

# CAVEATS

需要联网以下载最新版本。可能需要提升的权限，具体取决于 OpenCode 二进制文件的安装位置。

# TAGLINE

管理 Sailfish OS 开发设备

# TLDR

**列出可用设备**

```sfdk device```

**显示设备信息**

```sfdk device info [device_name]```

**设置默认设备**

```sfdk device set [device_name]```

# SYNOPSIS

**sfdk device** [_command_] [_options_]

# PARAMETERS

**list**
> 列出可用设备。

**info** _name_
> 显示设备信息。

**set** _name_
> 设置默认设备。

# DESCRIPTION

**sfdk device** 管理用于部署和测试的 Sailfish OS 设备和模拟器。属于 Sailfish SDK 的一部分。

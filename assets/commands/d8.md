# TAGLINE

V8 JavaScript 引擎开发者 Shell

# TLDR

**启动交互式** JavaScript REPL

```d8```

**运行 JavaScript 文件**

```d8 [script.js]```

**从命令行求值代码**

```d8 -e "[console.log(1+2)]"```

**向脚本传递参数**（通过 `arguments` 获取）

```d8 [script.js] -- [arg1] [arg2]```

**启用 staged harmony**（接近稳定）特性

```d8 --harmony [script.js]```

**打印生成的字节码**用于分析

```d8 --print-bytecode [script.js]```

**启用 V8 原生函数**如 `%OptimizeFunctionOnNextCall`

```d8 --allow-natives-syntax [script.js]```

**为 tick 处理器生成 V8 性能分析文件**

```d8 --prof [script.js]```

# SYNOPSIS

**d8** [_V8-options_] [_script.js_] [**--**] [_arguments_]

# PARAMETERS

_script.js_
> 要执行的 JavaScript 文件。若省略，`d8` 会启动交互式 Shell。

**-e** _code_
> 执行给定的 JavaScript 源码字符串。

**--harmony**
> 启用 staged Harmony（ECMAScript 提案）特性。

**--print-bytecode**
> 打印为每个函数生成的 Ignition 字节码。

**--trace-opt**, **--trace-deopt**
> 记录 TurboFan 的优化与去优化决策。

**--prof**
> 写出 `v8.log` 性能分析输出，供 `tools/tick-processor` 使用。

**--allow-natives-syntax**
> 允许使用带 `%` 前缀的 V8 运行时函数，例如 `%OptimizeFunctionOnNextCall`。

**--help**
> 列出所有支持的 V8 标志及简要说明。

**--**
> 分隔符：其后的所有内容都会通过 `arguments` 数组传递给脚本。

# DESCRIPTION

**d8** 是 V8 自带的开发者 Shell，随 V8 JavaScript 引擎源码树一同发布。它提供了一个极简的 JavaScript 执行环境，用于测试引擎、进行基准测试，以及探究 V8 如何编译和优化代码。

与 Node.js 或浏览器不同，**d8** 几乎不暴露任何宿主 API。作为交换，它暴露了 V8 特有的钩子，例如 Ignition 字节码转储、TurboFan 优化追踪、堆统计信息和运行时内部函数。该 Shell 为文件 I/O（`read`、`load`、`readline`）和输出（`print`、`console.log`）提供了少量便捷的全局对象。

完整的标志列表请运行 `d8 --help`；标志数量庞大且在 V8 各版本之间会有变化。

# CAVEATS

**d8** 是开发工具而非运行时：除了上述少量内建功能外，它没有 `setTimeout`、`fetch`、模块解析器或文件系统 API。行为和标志名在 V8 版本之间经常变化，二进制文件通常需要从源码构建 V8 或通过 `jsvu`/`esvu` 获取。`--allow-natives-syntax` 对应的运行时函数并不稳定，仅供 V8 开发使用。

# HISTORY

**d8** 是 **V8** 的调试 Shell，V8 是 Google 于 **2008 年**随 Chrome 发布而开源的 JavaScript 引擎。这个名字是引擎名称的缩写形式。它一直是 V8 工程师的主要试验场，也是研究代码优化机制的 JavaScript 性能研究者的常用工具。

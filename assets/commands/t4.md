# TAGLINE

用于代码生成的 T4 文本模板处理器

# TLDR

**处理** T4 模板并将输出写入文件

```t4 [template.tt] -o [output.cs]```

带参数**处理**模板

```t4 [template.tt] -o [output.cs] -p:[Name]="[value]"```

从 stdin **处理**模板并写到 stdout

```echo '[<#= DateTime.Now #>]' | t4 -o -```

将模板**预处理**为运行时类

```t4 -c [ClassName] [template.tt] -o [Template.cs]```

带类型化参数**处理**模板

```echo '<#@ parameter name="[Date]" type="System.DateTime" #><#=$"{[Date]:dddd}"#>' | t4 -o - -p:[Date]="[2024/03/08]"```

# SYNOPSIS

**t4** [_options_] [_template_]

# PARAMETERS

**-o** _file_
> 输出文件路径；用 **-** 表示标准输出

**-p:**_name_**=**_value_
> 向模板传递参数值（可重复）

**-c** _classname_
> 将模板预处理为运行时模板类

**-r** _assembly_
> 引用一个程序集

**-u** _namespace_
> 导入一个命名空间

**-I** _directory_
> 添加 include 搜索目录

**--dp** _processor!class!assembly_
> 添加自定义指令处理器

**--help**
> 显示帮助消息

**--version**
> 显示版本信息

# DESCRIPTION

**t4** 是一个处理 T4（Text Template Transformation Toolkit）模板的命令行工具。T4 是一种通用的方式，可以用 C# 生成任何类型的文本或代码文件。它是 **Mono.TextTemplating** 的一部分，后者是 Visual Studio T4 文本模板化引擎的现代开源重实现。

该工具有两种工作模式：直接模板处理模式立即生成输出文件；预处理模式则把模板转换为运行时模板类，可嵌入应用程序并在运行时执行。

模板使用由 **<#** 和 **#>** 标签界定的 C# 代码块来输出动态内容。parameter 指令支持将命令行字符串值自动转换成模板中指定的类型。该工具可以从标准输入读取模板并把输出写入标准输出，便于集成到管道中。

# CAVEATS

需要安装 **.NET SDK**（6.0 或更高版本）。可用 **dotnet tool install -g dotnet-t4** 全局安装此工具。在某些边缘情况下与原版 Visual Studio T4 引擎有所不同。为 Visual Studio 编写的模板可能需要少量调整才能完全兼容。

# HISTORY

T4（Text Template Transformation Toolkit）最初是 **Visual Studio** 中用于代码生成的组件。**Mono.TextTemplating** 项目将该引擎重新实现为开源、跨平台的替代品，此后不断演进，在原版基础上加入了许多改进，包括对最新 .NET API 和 C# 语言特性的支持。该命令行工具于 **2020 年**首次作为 **.NET 全局工具**发布。

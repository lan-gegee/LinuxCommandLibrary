# TAGLINE

激活已定义的存储池

# TLDR

**启动存储池**

```virsh pool-start [pool]```

# SYNOPSIS

**virsh** **pool-start** _pool_

# DESCRIPTION

**virsh pool-start** 激活一个已定义的存储池。使存储池可用于创建和使用卷。启动前必须先定义存储池。

# TAGLINE

移除 npm registry 上软件包的星标

# TLDR

**取消软件包星标**

```npm unstar [package]```

**取消多个软件包的星标**

```npm unstar [pkg1] [pkg2]```

# SYNOPSIS

**npm** **unstar** _package_...

# DESCRIPTION

**npm unstar** 移除 npm registry 上软件包的星标，是 npm star 操作的反向操作。需要 npm 身份验证。

# INSTALL

```pacman: sudo pacman -S npm```

```apk: sudo apk add npm```

```brew: brew install npm```

# TAGLINE

在终端中浏览 Wikipedia

# TLDR

**启动 Wikipedia 浏览器**

```wiki-tui```

# SYNOPSIS

**wiki-tui**

# DESCRIPTION

**wiki-tui** 是一个简洁快速的 Wikipedia TUI 客户端。它提供带预览的丰富搜索结果、支持可点击链接和格式化文本的文章查看、可跳转章节的目录、分层式文章导航以及类似 vim 的按键绑定。支持多种 Wikipedia 语言版本。

# HISTORY

**wiki-tui** 由 **Builditluc** 创建，使用 **Rust** 编写。

# INSTALL

```pacman: sudo pacman -S wiki-tui```

```nix: nix profile install nixpkgs#wiki-tui```

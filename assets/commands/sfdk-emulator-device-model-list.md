# TAGLINE

列出可用的 Sailfish 模拟器设备型号

# TLDR

**列出可用设备型号**

```sfdk emulator device-model list```

# SYNOPSIS

**sfdk emulator device-model list** [_options_]

# DESCRIPTION

**sfdk emulator device-model list** 显示 Sailfish OS 模拟器可用的设备型号。属于 Sailfish SDK 的一部分。

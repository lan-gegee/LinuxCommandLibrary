# TAGLINE

进入 Sailfish SDK 维护模式

# TLDR

**进入 SDK 维护模式**

```sfdk maintain```

**运行维护命令**

```sfdk maintain [command]```

# SYNOPSIS

**sfdk maintain** [_command_]

# DESCRIPTION

**sfdk maintain** 进入 SDK 维护模式，用于管理目标、工具和 SDK 组件。属于 Sailfish SDK 的一部分。

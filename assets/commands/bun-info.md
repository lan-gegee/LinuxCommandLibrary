# TAGLINE

显示系统和项目诊断信息

# TLDR

**显示系统与项目信息**

```bun info```

以 JSON 格式**显示信息**

```bun info --json```

# SYNOPSIS

**bun** **info** [_options_]

# PARAMETERS

**--json**
> 以 JSON 格式输出信息。

# DESCRIPTION

**bun info** 显示关于 Bun 安装、系统环境和当前项目的诊断信息，包括 Bun 版本、操作系统、CPU 架构、内存以及项目配置。

可用于排查问题或在报告 bug 时提供上下文信息。

# INSTALL

```pacman: sudo pacman -S bun```

```brew: brew install bun```

```nix: nix profile install nixpkgs#bun```

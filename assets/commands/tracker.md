# TAGLINE

在终端中实时跟踪卫星并预测轨道

# TLDR

**启动卫星跟踪 TUI**

```tracker```

# SYNOPSIS

**tracker** [_options_]

# DESCRIPTION

**tracker** 是一个基于终端的应用程序，使用 SGP4 模型进行实时卫星跟踪和轨道预测。它会通过互联网自动获取和更新轨道根数（TLE 数据），并显示天图视图和世界地图轨迹。

# HISTORY

**tracker** 由 **ShenMian** 创建，使用 **Rust** 编写。

# INSTALL

```brew: brew install tracker```

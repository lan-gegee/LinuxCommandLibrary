# TAGLINE

MongoDB 数据库的 TUI 管理工具

# TLDR

**启动 MongoDB TUI**

```vi-mongo```

# SYNOPSIS

**vi-mongo**

# DESCRIPTION

**vi-mongo** 是一个用于管理 MongoDB 数据库的终端用户界面。它支持对文档的 CRUD 操作、集合管理、集合名和数据库名自动补全、查询历史，以及包括正则表达式和 ISODate() 在内的标准 MongoDB Shell 语法。提供多种配色主题。

# HISTORY

**vi-mongo** 由 **kopecmaciej** 开发，使用 **Go** 编写。

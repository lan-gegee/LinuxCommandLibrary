# TAGLINE

p5 的 CLI 工具

# TLDR

**创建新项目**

```p5 new [project_name]```

**生成 sketch**

```p5 generate [sketch_name]```

**运行 sketch 服务器**

```p5 run```

**列出可用模板**

```p5 list```

# SYNOPSIS

**p5** [_command_] [_options_]

# PARAMETERS

**new** _NAME_
> 创建新项目。

**generate** _NAME_
> 生成 sketch。

**run**
> 启动开发服务器。

**list**
> 列出模板。

**--help**
> 显示帮助信息。

# DESCRIPTION

**p5** 是面向 p5.js 创意编程的 CLI 工具。用于搭建和管理项目骨架。

该工具帮助创建 p5.js sketch，实现开发流程自动化。

# CAVEATS

需要 Node.js 和 p5.js 库。输出基于 Web。

# HISTORY

p5 CLI 的创建目的是简化 **p5.js 项目**的搭建与开发。

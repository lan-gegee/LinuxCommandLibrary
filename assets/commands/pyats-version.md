# TAGLINE

显示 pyATS 框架版本信息

# TLDR

**显示 pyATS 版本**

```pyats version```

**显示所有软件包版本**

```pyats version --all```

**检查更新**

```pyats version --check```

# SYNOPSIS

**pyats version** [_options_]

# PARAMETERS

**--all**
> 显示所有 pyATS 软件包版本。

**--check**
> 检查可用的更新。

**--json**
> 以 JSON 格式输出。

# DESCRIPTION

**pyats version** 显示 pyATS 框架的版本信息。列出已安装的软件包版本并检查更新。属于 Cisco pyATS 网络测试框架的一部分。

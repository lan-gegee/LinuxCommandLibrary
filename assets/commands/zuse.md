# TAGLINE

终端上简约时尚的 IRC 客户端

# TLDR

**启动 IRC 客户端**

```zuse```

# SYNOPSIS

**zuse** [_options_]

# DESCRIPTION

**ZUSE** 是一款用 Bubble Tea 构建的现代 IRC 客户端，特色包括面向多频道的分栏布局、服务器管理，以及受合成波（synthwave）启发的美学风格。它为 Nightride FM 社区而建，专注于干净、无干扰的终端聊天体验。

# HISTORY

**ZUSE** 由 **Baby Commando**（babycommando）创建，使用 **Go** 编写。

# INSTALL

```nix: nix profile install nixpkgs#zuse```

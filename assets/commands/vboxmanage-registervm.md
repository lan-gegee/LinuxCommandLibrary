# TAGLINE

将现有虚拟机注册到 VirtualBox

# TLDR

**注册虚拟机**

```vboxmanage registervm [path/to/vmname.vbox]```

# SYNOPSIS

**vboxmanage** **registervm** _vmfile_

# DESCRIPTION

**vboxmanage registervm** 将现有的虚拟机配置添加到 VirtualBox。适用于手动复制虚拟机文件后，或重新注册已被移除的虚拟机。参数为 .vbox 配置文件的路径。

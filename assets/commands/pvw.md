# TAGLINE

基于终端的端口查看器

# TLDR

**启动端口查看器 TUI**

```pvw```

# SYNOPSIS

**pvw** [_options_]

# DESCRIPTION

**pvw** 是一个基于终端的端口查看器，提供简洁直观的界面来监控系统上正在使用的端口。它支持基于键盘的导航，用于查看打开和关闭的端口。

# HISTORY

**pvw** 由 **allyring** 创建，使用 **Go** 编写。

# INSTALL

```aur: yay -S pvw```

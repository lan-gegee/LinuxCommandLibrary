# TAGLINE

查看 Rust 工具的 man page

# TLDR

**打开 man page**

```rustup man [command]```

**打开 cargo 的 man page**

```rustup man cargo```

**打开 rustc 的 man page**

```rustup man rustc```

# SYNOPSIS

**rustup** **man** [_options_] _command_

# PARAMETERS

**--toolchain** _name_
> 使用指定的工具链。

# DESCRIPTION

**rustup man** 打开 Rust 工具的手册页。提供对 cargo、rustc 及其他工具文档的访问。需要安装 man pages 组件。

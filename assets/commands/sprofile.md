# TAGLINE

在终端中查看 Spotify 收听动态

# TLDR

**启动 Spotify 动态查看器**

```sprofile```

# SYNOPSIS

**sprofile**

# DESCRIPTION

**sprofile** 是一个用于查看 Spotify 收听动态的 TUI 应用。它基于 Ratatui 框架构建，提供交互式终端界面，用于查看你的 Spotify 历史记录和个人资料数据。

# HISTORY

**sprofile** 由 **Sushant Ray**（GoodBoyNeon）创建，使用 **Rust** 编写。

# INSTALL

```aur: yay -S sprofile```

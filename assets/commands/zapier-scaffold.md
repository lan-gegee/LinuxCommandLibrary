# TAGLINE

生成 Zapier 集成样板代码

# TLDR

**搭建触发器脚手架**

```zapier scaffold trigger [name]```

**搭建创建操作脚手架**

```zapier scaffold create [name]```

**搭建搜索操作脚手架**

```zapier scaffold search [name]```

# SYNOPSIS

**zapier** **scaffold** _type_ _name_ [_options_]

# PARAMETERS

**trigger** _name_
> 创建触发器脚手架。

**create** _name_
> 创建操作（create）脚手架。

**search** _name_
> 创建搜索脚手架。

**resource** _name_
> 创建资源脚手架。

# DESCRIPTION

**zapier scaffold** 为集成组件生成样板代码，用起始代码创建触发器、操作和搜索。可加快集成开发速度。

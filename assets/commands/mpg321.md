# TAGLINE

命令行 MP3 播放器，mpg123 的自由软件克隆

# TLDR

**播放 MP3 文件**

```mpg321 [file.mp3]```

**播放多个文件**

```mpg321 [file1.mp3] [file2.mp3]```

**从 URL 播放**

```mpg321 [http://example.com/audio.mp3]```

**随机顺序播放**

```mpg321 -z [*.mp3]```

**调整音量播放**

```mpg321 -g [50] [file.mp3]```

**静默模式**（无输出）

```mpg321 -q [file.mp3]```

**输出到 WAV 文件**

```mpg321 -w [output.wav] [input.mp3]```

**循环播放**

```mpg321 --loop [3] [file.mp3]```

# SYNOPSIS

**mpg321** [_-w output.wav_] [_-g gain_] [_-z_] [_-q_] [_options_] _files_

# PARAMETERS

**-w** _FILE_
> 输出到 WAV 文件而不是播放。

**-g** _GAIN_
> 音频增益百分比（默认 100，更高的值会放大音量）。

**-z**
> 随机打乱播放列表。

**-q**, **--quiet**
> 静默模式。

**--loop** _N_
> 循环播放 N 次。

**-@** _FILE_
> 从文件读取播放列表。

**-o** _DRIVER_
> 音频输出驱动。

**-a** _DEVICE_
> 音频设备。

**-b** _SIZE_
> 缓冲区大小（KB）。

**-r**
> 使用远程控制接口。

**-s**
> 输出到 stdout（供管道使用）。

**-v**
> 详细输出。

# DESCRIPTION

**mpg321** 是一个命令行 MP3 播放器，是 mpg123 的自由软件克隆。它使用 libmad 库解码并播放 MPEG 音频文件。

该播放器支持本地文件、播放列表和 HTTP 流。随机模式会打乱播放顺序，循环模式则重复曲目或播放列表。

WAV 输出将 MP3 解码为未压缩音频，可用于刻录 CD 或转换格式。结合管道使用时，还能把音频输送给其他程序。

远程控制模式从 stdin 接受命令，便于与前端应用集成。命令可控制播放、跳转和音量。

增益调节用于缩放音频输出。超过 100 的值会放大声音并可能造成削波。该设置有助于统一各曲目之间的音量。

# CAVEATS

仅解码 MPEG 音频（layer 1、2、3）——不支持其他格式。某些 HTTP 流可能无法播放。不支持无缝播放。该项目基本已停止维护；现在首选 mpg123 作为替代。

# HISTORY

**mpg321** 由 **Joe Drew** 于 **2001 年**创建，当时 mpg123 的许可证状况不明，它作为自由替代方案应运而生。它采用了明确属于自由软件的 libmad 解码器。当 mpg123 转为 LGPL 许可后，两个播放器都继续开发。

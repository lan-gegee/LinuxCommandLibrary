# TAGLINE

将 IBM Cloud CLI 更新到最新版本

# TLDR

**更新 IBM Cloud CLI**

```ibmcloud update```

**强制更新**

```ibmcloud update -f```

**检查更新**

```ibmcloud update --check```

# SYNOPSIS

**ibmcloud** **update** [_options_]

# PARAMETERS

**-f**, **--force**
> 无需确认强制更新。

**--check**
> 检查是否有可用更新。

# DESCRIPTION

**ibmcloud update** 将 IBM Cloud CLI 更新到最新版本。使用 **--check** 可以查看是否有可用更新而不进行安装。

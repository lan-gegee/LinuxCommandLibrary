# DESCRIPTION

**2048** 是一款滑块拼图游戏。目标是在 4x4 网格上合并数字方块，创造出数字为 2048 的方块。

玩法：
- 方块沿所选方向滑动，直到撞到墙壁或另一个方块
- 数字相同的方块合并为两者之和的新方块
- 每次移动后，会随机出现一个新方块（2 或 4）
- 当无路可走时游戏结束

策略上应把最大的方块固定在角落，并循序渐进地堆叠相邻方块。达到 2048 后如果想追求更高分数，游戏还可以继续。

存在多种终端实现，包括用不同语言编写的文本版本以及原版浏览器游戏。

# CAVEATS

这是热门拼图游戏的终端实现。具体特性可能因实现而异。

游戏需要支持相应界面的终端（通常基于 ncurses）。

前期有效的策略未必能一直适用——更大的方块需要更细致的规划。

# HISTORY

2048 由 **Gabriele Cirulli** 于 **2014 年 3 月**作为一个周末项目创作。它迅速走红，催生了无数克隆和变体。它是 1024 的克隆（而 1024 本身是 Threes! 的克隆），并基于 Saming 更早的 2048 实现。

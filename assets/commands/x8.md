# TAGLINE

隐藏 Web 参数发现工具

# TLDR

**查找隐藏参数**

```x8 -u [https://example.com/page] -w [params.txt]```

**使用自定义请求头**

```x8 -u [url] -w [wordlist] -H "[Cookie: value]"```

**输出到文件**

```x8 -u [url] -w [wordlist] -o [output.txt]```

**多个 URL**

```x8 -l [urls.txt] -w [params.txt]```

# SYNOPSIS

**x8** [_-u url_] [_-w wordlist_] [_-H header_] [_options_]

# PARAMETERS

**-u** _URL_
> 目标 URL。

**-l** _FILE_
> URL 列表。

**-w** _FILE_
> 参数字典文件。

**-H** _HEADER_
> 自定义请求头。

**-o** _FILE_
> 输出文件。

# DESCRIPTION

**x8** 是一款面向 Web 应用的隐藏参数发现工具，用于授权的安全测试和漏洞赏金研究。它使用字典中的候选参数名发送请求，并分析响应以识别应用接受但未公开文档化的参数。

该工具支持通过多种 HTTP 方法进行发现，包括 GET 查询参数、POST 正文数据和 HTTP 请求头。并发请求处理支持快速扫描，还可以从文件中批量处理多个 URL。

# CAVEATS

仅限授权使用。可能被检测到。Rust 实现。

# HISTORY

**x8** 是为安全测试期间发现 Web 应用中的隐藏参数而创建的。

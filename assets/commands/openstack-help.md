# TAGLINE

显示 OpenStack CLI 命令的帮助信息

# TLDR

**显示一般帮助**

```openstack help```

**显示某命令的帮助**

```openstack help [server create]```

**列出所有命令**

```openstack command list```

# SYNOPSIS

**openstack help** [_command_]

# PARAMETERS

_command_
> 要获取帮助的命令。

# DESCRIPTION

**openstack help** 显示 OpenStack CLI 命令的帮助信息，包括可用的子命令、选项和用法示例。属于 OpenStack 统一 CLI。

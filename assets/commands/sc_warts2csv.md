# TAGLINE

将 scamper warts 文件转换为 CSV 格式

# TLDR

**将 warts 转换为 CSV 格式**

```sc_warts2csv [input.warts] > [output.csv]```

# SYNOPSIS

**sc_warts2csv** [_options_] _file_

# PARAMETERS

**-t** _type_
> 要导出的测量类型。

# DESCRIPTION

**sc_warts2csv** 将 scamper 的 warts 二进制格式转换为 CSV，以便在电子表格或数据分析工具中处理。scamper 工具集的一部分。

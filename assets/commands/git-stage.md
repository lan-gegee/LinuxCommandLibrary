# TAGLINE

git add 的别名，用于暂存改动

# TLDR

**暂存文件**

```git stage [file]```

**暂存所有改动**

```git stage -A```

**交互式暂存**

```git stage -p```

# SYNOPSIS

**git** **stage** [_options_] [_files_...]

# DESCRIPTION

**git stage** 是 `git add` 的内置别名。它将改动暂存以待下次提交。与 "add" 相比，"stage" 一词更贴切地描述了把改动加入索引这一动作。

# TAGLINE

现代负载测试工具

# TLDR

**运行负载测试**

```k6 run [script.js]```

**指定虚拟用户数运行**

```k6 run --vus [10] --duration [30s] [script.js]```

**指定迭代次数运行**

```k6 run --iterations [100] [script.js]```

**云端执行**

```k6 cloud [script.js]```

**输出为 JSON**

```k6 run --out json=[results.json] [script.js]```

**中止时触发阈值**

```k6 run --throw-on-abort [script.js]```

# SYNOPSIS

**k6** _command_ [_options_] _script_

# PARAMETERS

**run** _SCRIPT_
> 运行负载测试脚本。

**cloud** _SCRIPT_
> 在 k6 Cloud 上运行。

**--vus** _N_
> 虚拟用户数。

**--duration** _TIME_
> 测试时长。

**--iterations** _N_
> 总迭代次数。

**--out** _OUTPUT_
> 输出目的地。

**--help**
> 显示帮助信息。

# DESCRIPTION

**k6** 是一个现代负载测试工具。它使用 JavaScript 编写测试脚本，并提供强大的 API。

该工具会生成详细的性能指标。它支持云端执行和 CI/CD 集成。

# CAVEATS

仅支持 JavaScript ES6 子集，不是 Node.js 运行时。云功能需要账户。

# HISTORY

k6 由 **Load Impact**（现 Grafana Labs）创建，是一个面向开发者的负载测试工具。

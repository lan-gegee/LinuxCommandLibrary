# TAGLINE

带实时可视化的 TUI 音频分析器

# TLDR

**以麦克风输入启动**

```soundscope```

**分析音频文件**

```soundscope [path/to/audio.mp3]```

# SYNOPSIS

**soundscope** [_path/to/audio_]

# DESCRIPTION

**soundscope** 是一款跨平台 CLI 工具，用于实时分析音频文件和麦克风输入。它直接在终端中显示波形、FFT 频谱和 LUFS 响度测量。支持自定义主题以及可悬停查看的频率/振幅详情。

# HISTORY

**soundscope** 由 **bananaofhappiness** 创建，使用 **Rust** 编写。

# INSTALL

```pacman: sudo pacman -S soundscope```

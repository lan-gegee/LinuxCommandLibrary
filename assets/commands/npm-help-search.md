# TAGLINE

搜索 npm 帮助文档

# TLDR

**搜索帮助主题**

```npm help-search [term]```

**以完整输出搜索**

```npm help-search -l [term]```

# SYNOPSIS

**npm** **help-search** _text_...

# PARAMETERS

**-l**, **--long**
> 显示完整的说明。

# DESCRIPTION

**npm help-search** 搜索 npm 帮助文档，查找与搜索词匹配的帮助主题。适合用来发现相关的 npm 命令和概念。

# INSTALL

```pacman: sudo pacman -S npm```

```apk: sudo apk add npm```

```brew: brew install npm```

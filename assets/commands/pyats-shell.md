# TAGLINE

交互式 pyATS 测试 shell

# TLDR

**启动 pyATS shell**

```pyats shell```

**加载 testbed 启动**

```pyats shell --testbed-file [testbed.yaml]```

# SYNOPSIS

**pyats shell** [_options_]

# PARAMETERS

**--testbed-file** _file_
> Testbed YAML 文件。

**--no-ipython**
> 使用纯 Python shell。

# DESCRIPTION

**pyats shell** 启动一个已加载 pyATS 库的交互式 Python shell。它会预加载 testbed 和设备对象，用于网络测试和自动化。Cisco pyATS 框架的一部分。

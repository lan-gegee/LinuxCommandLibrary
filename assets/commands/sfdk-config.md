# TAGLINE

管理 Sailfish SDK 配置设置

# TLDR

**显示当前配置**

```sfdk config```

**设置目标设备**

```sfdk config --device [device_name]```

**设置构建目标**

```sfdk config --target [target_name]```

# SYNOPSIS

**sfdk config** [_options_]

# PARAMETERS

**--device** _name_
> 设置目标设备。

**--target** _name_
> 设置构建目标。

**--specfile** _file_
> 设置 spec 文件。

# DESCRIPTION

**sfdk config** 管理 Sailfish SDK 配置，设置构建目标、设备和项目选项。属于 Sailfish SDK 的一部分。

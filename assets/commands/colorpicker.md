# TAGLINE

屏幕取色工具

# TLDR

**启动取色器**

```colorpicker```

**取色并按指定格式输出**

```colorpicker --format [hex|rgb|hsl]```

**将取到的颜色复制**到剪贴板

```colorpicker --clipboard```

# SYNOPSIS

**colorpicker** [_options_]

# PARAMETERS

**--format** _format_
> 输出格式：hex、rgb、hsl。

**--clipboard**
> 将结果复制到剪贴板。

# DESCRIPTION

**colorpicker** 是一个从屏幕上选取颜色的命令行工具。它允许你选择显示器上的任意像素，并以多种格式获取其颜色值。

对于需要从现有界面或图像中快速取色的设计师和开发者来说非常实用。

# TAGLINE

为 Sailfish 应用构建 RPM 软件包

# TLDR

**创建 RPM 软件包**

```sfdk package```

**打包时包含调试信息**

```sfdk package --debuginfo```

# SYNOPSIS

**sfdk package** [_options_]

# PARAMETERS

**--debuginfo**
> 包含调试信息。

**--no-fix-version**
> 不自动修正版本号。

# DESCRIPTION

**sfdk package** 为 Sailfish OS 应用程序构建 RPM 软件包。属于 Sailfish SDK 的一部分。

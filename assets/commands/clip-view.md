# TAGLINE

显示系统剪贴板内容

# TLDR

**查看剪贴板内容**

```clip-view```

**以指定格式查看剪贴板**

```clip-view --format [text]```

# SYNOPSIS

**clip-view** [_options_]

# DESCRIPTION

**clip-view** 从命令行显示系统剪贴板的当前内容。它支持以不同格式查看剪贴板数据，便于检查剪贴板中当前存储的内容。

该工具对于涉及剪贴板的脚本化工作流特别有用，也适合调试复制粘贴问题——当你需要验证应用程序之间传输的确切内容时。

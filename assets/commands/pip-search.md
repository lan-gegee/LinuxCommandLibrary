# TAGLINE

在 PyPI 中搜索软件包（已废弃）

# TLDR

**搜索软件包**

```pip search [query]```

# SYNOPSIS

**pip** **search** _query_

# DESCRIPTION

**pip search** 曾用于按名称或描述在 PyPI 上搜索软件包。自 2020 年底起，由于自动化查询造成的资源消耗过大，PyPI 已禁用此命令。

# CAVEATS

此命令已不可用。PyPI 已停用 XML-RPC 搜索端点。请改为直接在 pypi.org 上搜索软件包。

# INSTALL

```apk: sudo apk add py3-pip```

# TAGLINE

逐页浏览 xz 压缩文件

# TLDR

**查看 xz 压缩文件**

```xzmore [file.xz]```

# SYNOPSIS

**xzmore** [_files_...]

# DESCRIPTION

**xzmore** 逐页显示 xz 压缩文件。使用 more 作为分页器。比 xzless 简单，但导航功能较少。按空格翻到下一页，按 q 退出。

# INSTALL

```apt: sudo apt install xz-utils```

```dnf: sudo dnf install xz```

```pacman: sudo pacman -S xz```

```apk: sudo apk add xz```

```zypper: sudo zypper install xz```

```brew: brew install xz```

```nix: nix profile install nixpkgs#xz```

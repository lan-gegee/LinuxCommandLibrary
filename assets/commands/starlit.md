# TAGLINE

极简且可定制的天气 CLI

# TLDR

**显示指定城市的天气**

```starlit [seattle]```

**启动交互式天气模式**

```starlit --interactive```

**打开配置文件进行编辑**

```starlit --edit```

# SYNOPSIS

**starlit** [_city_] [_options_]

# DESCRIPTION

**starlit** 是一个极简且可定制的天气 CLI，由 OpenWeatherMap API 驱动，使用 Rich 库和终端文本特效进行样式呈现。它支持交互模式、自定义颜色主题和多语言输出。

# CAVEATS

需要 OpenWeatherMap API 密钥。

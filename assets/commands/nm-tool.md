# TAGLINE

显示 NetworkManager 信息

# TLDR

**显示网络状态**

```nm-tool```

**显示所有信息**

```nm-tool --all```

# SYNOPSIS

**nm-tool** [_options_]

# PARAMETERS

**--all**
> 显示所有细节。

**--help**
> 显示帮助信息。

# DESCRIPTION

**nm-tool** 显示 NetworkManager 信息。展示网络连接和状态。

该工具查询 NetworkManager。已被弃用，建议改用 nmcli。

# CAVEATS

已弃用。请改用 nmcli。需要 NetworkManager。

# HISTORY

nm-tool 是最早的 **NetworkManager** CLI 工具，现已被 nmcli 取代。

# TAGLINE

在 Sailfish 构建环境中打开 Shell

# TLDR

**在构建环境中打开 Shell**

```sfdk build-shell```

**在构建环境中运行命令**

```sfdk build-shell [command]```

# SYNOPSIS

**sfdk build-shell** [_command_]

# DESCRIPTION

**sfdk build-shell** 在 Sailfish OS 构建环境内部打开交互式 Shell 或运行命令。属于 Sailfish SDK 的一部分。

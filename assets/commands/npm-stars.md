# TAGLINE

显示某用户收藏的软件包

# TLDR

**列出收藏的软件包**

```npm stars```

**列出指定用户的收藏**

```npm stars [username]```

# SYNOPSIS

**npm** **stars** [_user_]

# PARAMETERS

**--registry** _URL_
> npm registry URL（默认：https://registry.npmjs.org/）。

# DESCRIPTION

**npm stars** 显示某用户收藏的软件包。默认显示你自己的收藏。提供用户名即可查看其他用户的收藏。

# INSTALL

```pacman: sudo pacman -S npm```

```apk: sudo apk add npm```

```brew: brew install npm```

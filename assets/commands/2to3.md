# TAGLINE

Python 2 到 Python 3 的自动代码转换器

# TLDR

只**显示改动而不应用**

```2to3 [script.py]```

**就地转换文件**

```2to3 -w [script.py]```

**转换整个目录**

```2to3 -w [directory/]```

只**应用指定的修复器**

```2to3 -f [print] -f [import] [script.py]```

**列出可用的修复器**

```2to3 -l```

**就地转换且不创建 .bak 备份文件**

```2to3 -w -n [script.py]```

将转换后的文件**写入其他目录**

```2to3 -w -n -o [out_dir/] [script.py]```

# SYNOPSIS

**2to3** [_options_] _file_|_directory_

# PARAMETERS

**-w**, **--write**
> 将改动写回文件

**-n**, **--nobackups**
> 不创建 .bak 备份文件

**-f** _fixer_, **--fix** _fixer_
> 应用指定的修复器

**-x** _fixer_, **--nofix** _fixer_
> 排除指定的修复器

**-l**, **--list-fixes**
> 列出可用的修复器

**-p**, **--print-function**
> 将 **print** 视为函数（跳过 print 修复器）。当文件已经使用 **from __future__ import print_function** 时有用。

**-d**, **--doctests_only**
> 只修复文件中的 doctest。

**-W**, **--write-unchanged-files**
> 即使文件未发生变化也写出输出（配合 **-o** 使用时有用）。

**--add-suffix** _SUFFIX_
> 在输出文件名后附加此后缀，而不是直接覆盖。

**-j** _n_, **--processes** _n_
> 以 n 个进程并行运行

**-o** _dir_, **--output-dir** _dir_
> 将转换后的文件写到指定目录

**-v**, **--verbose**
> 输出更详细的信息

# DESCRIPTION

**2to3** 是一个 Python 2 到 Python 3 的自动代码翻译器。它解析 Python 2 源代码，并应用"修复器"（fixers）把不兼容的语法和库调用转换为对应的 Python 3 写法。

常见的转换包括：
- **print** 语句转换为 **print()** 函数
- **unicode** 转换为 **str**，**str** 转换为 **bytes**
- **raw_input()** 转换为 **input()**
- 迭代器方法（.iteritems() 转换为 .items()）
- **except Exception, e** 转换为 **except Exception as e**
- 库名重命名（urllib、ConfigParser 等）

2to3 能处理大部分机械性改动，但 Python 2 与 3 之间的语义差异仍可能需要人工审查。

# CAVEATS

2to3 只做语法层面的修改，无法覆盖所有差异。代码行为仍可能不同，尤其在以下方面：
- 字符串/字节处理
- 整数除法
- 字典顺序（Python 3.7 之前）
- Unicode 文本处理

不带 **-n** 运行 **-w** 会产生 .bak 文件，可能弄乱版本控制。

Python 2 已于 2020 年 1 月停止维护。对于大型项目，建议考虑 **python-modernize** 或 **futurize** 等更现代的移植工具。

# TAGLINE

显示 Sailfish 模拟器设备型号详情

# TLDR

**显示设备型号详情**

```sfdk emulator device-model show [model_name]```

# SYNOPSIS

**sfdk emulator device-model show** _model_

# DESCRIPTION

**sfdk emulator device-model show** 显示特定 Sailfish OS 模拟器设备型号的详细信息。属于 Sailfish SDK 的一部分。

# TAGLINE

先运行 npm install 再运行 npm test

# TLDR

**安装并测试**

```npm install-test```

**简写形式**

```npm it```

# SYNOPSIS

**npm** **install-test**

# DESCRIPTION

**npm install-test** 先运行 npm install 再运行 npm test，把依赖安装和测试执行合二为一。别名：npm it。

# INSTALL

```pacman: sudo pacman -S npm```

```apk: sudo apk add npm```

```brew: brew install npm```

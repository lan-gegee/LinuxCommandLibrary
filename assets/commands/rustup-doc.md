# TAGLINE

在浏览器中打开本地 Rust 文档

# TLDR

**打开 Rust 文档**

```rustup doc```

**打开 The Book**

```rustup doc --book```

**打开标准库文档**

```rustup doc --std```

**打开特定 crate 的文档**

```rustup doc --core```

# SYNOPSIS

**rustup** **doc** [_options_] [_topic_]

# PARAMETERS

**--book**
> The Rust Programming Language（Rust 程序设计语言）。

**--std**
> 标准库文档。

**--reference**
> The Rust Reference（Rust 参考手册）。

**--core**
> core 库文档。

**--alloc**
> alloc 库文档。

**--path**
> 打印路径而不打开浏览器。

# DESCRIPTION

**rustup doc** 在浏览器中打开本地的 Rust 文档。提供对 The Book、标准库和参考文档的离线访问。

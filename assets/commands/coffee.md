# TAGLINE

CoffeeScript 编译器和运行时

# TLDR

**将 CoffeeScript 文件编译**为 JavaScript

```coffee -c [script.coffee]```

**编译并输出**到指定目录

```coffee -c -o [output/] [script.coffee]```

**监视并在文件变化时重新编译**

```coffee -w -c [script.coffee]```

**直接运行 CoffeeScript 文件**

```coffee [script.coffee]```

**启动交互式 REPL**

```coffee```

**从命令行求值 CoffeeScript 代码**

```coffee -e "[console.log 'Hello']"```

**编译目录中的所有文件**

```coffee -c [src/]```

**打印编译后的 JavaScript** 而不保存

```coffee -p [script.coffee]```

# SYNOPSIS

**coffee** [_options_] [_path/to/script.coffee_] [_arguments_]

# PARAMETERS

**-c**, **--compile**
> 将 CoffeeScript 编译为 JavaScript 文件。

**-o** _DIR_, **--output** _DIR_
> 编译后 JavaScript 的输出目录。

**-w**, **--watch**
> 监视文件变化并重新编译。

**-p**, **--print**
> 将编译后的 JavaScript 打印到标准输出。

**-e** _CODE_, **--eval** _CODE_
> 求值一段 CoffeeScript 代码字符串。

**-b**, **--bare**
> 编译时不添加顶层函数安全包装。

**-m**, **--map**
> 在生成 JavaScript 的同时生成 source map。

**-M**, **--inline-map**
> 将 source map 内嵌到 JavaScript 文件中。

**-n**, **--nodes**
> 打印源码的解析树（AST）。

**-t**, **--transpile**
> 将输出经 Babel 转译以兼容 ES5。

**--no-header**
> 不输出 "Generated by CoffeeScript" 头部注释。

**-h**, **--help**
> 显示帮助信息。

**-v**, **--version**
> 显示版本信息。

# DESCRIPTION

**coffee** 是 CoffeeScript 的命令行编译器和运行时。CoffeeScript 是一种可编译为 JavaScript 的编程语言，提供受 Ruby 和 Python 启发的更简洁语法，具有显著的空白缩进、隐式返回以及针对常见模式的语法糖。

该编译器可以输出 JavaScript 文件、直接运行 CoffeeScript，或提供交互式 REPL 供试验。监视模式支持实时开发工作流，文件保存时会自动重新编译。

CoffeeScript 编译出的 JavaScript 可读性好且遵循最佳实践。借助 source map，即使运行的是编译后的 JavaScript，也可以用原始 CoffeeScript 进行调试。bare 选项会移除 IIFE 包装，以便与模块系统配合使用。

# CAVEATS

CoffeeScript 2 输出现代 JavaScript（ES6+），若要在旧浏览器中运行可能需要通过 **--transpile** 转译。显著的空白缩进要求缩进风格一致（空格或制表符，不可混用）。自 ES6 原生采纳了 CoffeeScript 的许多特性后，其使用量已大幅下降。

# HISTORY

CoffeeScript 由 Jeremy Ashkenas 创建，于 **2009 年 12 月**发布。它在 2010 年代初大受欢迎，尤其是在 Ruby on Rails 社区。尽管随着 ES6 采纳了许多 CoffeeScript 率先引入的特性，其使用量有所下降，但该项目仍在维护并被继续使用。

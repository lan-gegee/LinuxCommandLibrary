# TAGLINE

在终端中显示 ASCII 火焰动画

# TLDR

显示 **ASCII 火焰动画**

```cacafire```

# SYNOPSIS

**cacafire**

# DESCRIPTION

**cacafire** 使用 libcaca 库在终端中播放 ASCII 艺术火焰动画。它用彩色文本字符渲染出逼真的火焰效果。

按 **Space** 暂停/继续，按 **Esc** 退出，或用 Ctrl+C 中断。

# INSTALL

```apt: sudo apt install caca-utils```

```dnf: sudo dnf install caca-utils```

```apk: sudo apk add libcaca-apps```

```zypper: sudo zypper install caca-utils```

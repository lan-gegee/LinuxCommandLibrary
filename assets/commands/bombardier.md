# DESCRIPTION

**bombardier** 是一款受经典轰炸机游戏启发的终端街机游戏。玩家驾驶飞机横穿屏幕，投下炸弹摧毁下方的建筑物。每飞过一轮，飞机就会降低一些高度，玩家必须及时清出一条通路，以免撞上剩余的建筑物。

游戏操作简单：按空格键投掷炸弹。每轮的建筑物都是随机生成的。

# CAVEATS

需要支持 ncurses 的终端。玩法简单但容易上瘾。

# HISTORY

**bombardier** 的灵感源自可追溯到 **20 世纪 70 年代**的经典轰炸机游戏，尤其是早期家用电脑上的 Blitz 和 Bomber。

# TAGLINE

终端中的惬意打字速度测试器

# TLDR

**启动**交互式打字测试

```typioca```

**启动** SSH 服务器供远程打字测试

```typioca serve```

# SYNOPSIS

**typioca** [_command_]

# DESCRIPTION

**typioca** 是一款极简的基于终端的打字速度测试器，带有交互式 TUI 菜单。它提供准确的每分钟单词数（WPM）结果，支持按时间、单词数或句子数进行测试，并配有多个取自经典书籍的词表。测试模式和设置通过交互式菜单配置，而非 CLI 标志。

# HISTORY

**typioca** 由 **Lukas Bloznelis**（bloznelis）开发，使用 **Go** 编写。

# INSTALL

```zypper: sudo zypper install typioca```

```brew: brew install typioca```

```nix: nix profile install nixpkgs#typioca```

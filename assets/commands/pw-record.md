# TAGLINE

通过 PipeWire 将音频录制到文件

# TLDR

此命令是 **pw-cat --record** 的别名

查看原始命令的文档

```tldr pw-cat```

# SYNOPSIS

**pw-record** [_options_] [_file_]

# DESCRIPTION

**pw-record** 是 **pw-cat --record** 的便捷别名，从 PipeWire 捕获音频并保存到文件。它为录制音频流提供简单的接口。

# INSTALL

```apt: sudo apt install pipewire-bin```

```apk: sudo apk add pipewire-tools```

```zypper: sudo zypper install pipewire-tools```

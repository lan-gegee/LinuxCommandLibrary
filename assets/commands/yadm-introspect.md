# TAGLINE

显示 yadm 内部信息

# TLDR

**列出可用的 yadm 命令**

```yadm introspect commands```

**列出支持的配置选项**

```yadm introspect configs```

**显示仓库位置**

```yadm introspect repo```

**列出可用的命令行开关**

```yadm introspect switches```

# SYNOPSIS

**yadm** **introspect** _category_

# PARAMETERS

**commands**
> 列出可用的 yadm 命令。

**configs**
> 列出支持的配置选项。

**repo**
> 显示仓库路径。

**switches**
> 列出可用的命令行开关。

# DESCRIPTION

**yadm introspect** 报告 yadm 的内部数据。它的主要用途是支持命令行补全，但也可用于调试和脚本编写。

# TAGLINE

显示存储池详细信息

# TLDR

**显示池信息**

```virsh pool-info [pool]```

**显示所有池信息**

```virsh pool-list --details```

# SYNOPSIS

**virsh** **pool-info** _pool_

# DESCRIPTION

**virsh pool-info** 显示存储池详细信息，包括状态、容量、已分配空间和可用空间。适合用于监控存储使用情况。

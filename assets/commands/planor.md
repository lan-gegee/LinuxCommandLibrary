# TAGLINE

AWS、Vultr、Heroku 等云服务的 TUI 客户端

# TLDR

**启动云服务 TUI**

```planor```

# SYNOPSIS

**planor** [_options_]

# DESCRIPTION

**planor** 是一个终端用户界面，用于管理 AWS、Heroku、Vultr 和 Render 等多个云平台。它提供基于文本的界面，让你无需打开网页仪表盘即可与云服务交互、管理资源并监控部署。

# HISTORY

**planor** 由 **mrusme** 开发，使用 **Go** 编写。

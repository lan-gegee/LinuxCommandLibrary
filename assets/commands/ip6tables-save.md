# TAGLINE

保存当前 IPv6 防火墙规则

# TLDR

此命令是 IPv6 防火墙场景下 **iptables-save** 的别名

```tldr iptables-save```

# INSTALL

```pacman: sudo pacman -S iptables```

```apk: sudo apk add iptables```

```zypper: sudo zypper install iptables```

```brew: brew install iptables```

```nix: nix profile install nixpkgs#iptables```

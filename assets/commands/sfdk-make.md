# TAGLINE

在 Sailfish 构建环境中运行 make

# TLDR

**使用 make 构建项目**

```sfdk make```

**使用并行任务构建**

```sfdk make -j[4]```

**清理构建**

```sfdk make clean```

# SYNOPSIS

**sfdk make** [_make_options_]

# DESCRIPTION

**sfdk make** 在 Sailfish OS 构建环境内运行 make。属于 Sailfish SDK 的一部分。

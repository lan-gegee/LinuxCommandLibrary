# TAGLINE

现代化的声明式图表脚本语言

# TLDR

**将 D2 图表编译**为 SVG

```d2 [diagram.d2] [output.svg]```

**编译为 PNG** 格式

```d2 --format png [diagram.d2] [output.png]```

**监视变更**并自动重新编译

```d2 --watch [diagram.d2] [output.svg]```

**使用指定的布局引擎**

```d2 --layout [elk] [diagram.d2] [output.svg]```

**应用主题**

```d2 --theme [200] [diagram.d2] [output.svg]```

**格式化/美化打印** D2 文件

```d2 fmt [diagram.d2]```

# SYNOPSIS

**d2** [_options_] _input.d2_ [_output_]

# PARAMETERS

_INPUT_
> 要编译的 D2 源文件。

_OUTPUT_
> 输出文件路径（格式由扩展名推断）。

**--format** _FORMAT_
> 输出格式：svg、png、pdf。

**--layout** _ENGINE_
> 布局引擎：dagre（默认）、elk、tala。

**--theme** _ID_
> 主题 ID（0-200+）。

**--watch**, **-w**
> 监视输入文件，发生变更时重新编译。

**--sketch**
> 以手绘草图风格渲染。

**--pad** _N_
> 图表四周的留白（像素）。

**fmt**
> 格式化/重新缩进 D2 源文件。

**--help**
> 显示帮助信息。

# DESCRIPTION

**D2** 是一种现代的图表脚本语言，可将文本转换为图表。它使用声明式语法描述节点、连线和布局，无需手动定位即可生成专业外观的图表。

D2 支持多种图表类型，包括流程图、实体关系图、时序图和类图。这门语言注重可读性且对版本控制友好，布局全部自动处理。

该工具提供多个各有所长的布局引擎。监视模式支持编辑时的实时预览。主题提供统一的样式，草图模式则营造手绘美感。

# CAVEATS

复杂图表可能需要布局提示才能获得最佳效果。某些特性需要 TALA 布局引擎（专有软件）。大型图表渲染可能较慢。PNG 输出需要额外的依赖。

# HISTORY

D2 由 Terrastruct 创建并于 **2022 年**开源。它被设计为 Graphviz 等老牌图表工具的现代替代品，拥有更好的默认效果、更多的特性和开箱即用的美观外观。

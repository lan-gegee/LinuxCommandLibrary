# TAGLINE

Backblaze B2 云存储的命令行界面。

# TLDR

**授权**账户

```b2 account authorize [applicationKeyId] [applicationKey]```

**上传**文件

```b2 file upload [bucketName] [localFile] [remoteFileName]```

**下载**文件

```b2 file download b2://[bucketName]/[fileName] [localFile]```

**列出**存储桶

```b2 bucket list```

**列出**存储桶中的文件

```b2 ls --recursive b2://[bucketName]```

**同步**目录到存储桶

```b2 sync [localPath] b2://[bucketName]/[path]```

**删除**匹配某路径的文件

```b2 rm --recursive b2://[bucketName]/[path]```

# SYNOPSIS

**b2** _command_ [_options_]

# DESCRIPTION

**b2** 是 Backblaze B2 Cloud Storage 的命令行界面。它提供在 B2 存储桶中上传、下载和管理文件的工具，以更低的成本提供兼容 S3 的对象存储。

该工具支持大文件上传、版本控制和生命周期规则。第 4 版将命令重组为名词式分组，例如 `b2 account`、`b2 bucket`、`b2 file` 和 `b2 key`；旧的扁平式命令如 `upload-file` 和 `list-buckets` 已被弃用。

# PARAMETERS

**account authorize**
> 使用应用密钥 ID 和密钥进行身份验证。

**bucket create**
> 创建新的存储桶，例如 `b2 bucket create [name] allPrivate`。

**bucket list**
> 列出账户中的所有存储桶。

**file upload**
> 将单个本地文件上传到存储桶。

**file download**
> 根据 `b2://bucket/name` URI 下载文件。

**ls**
> 列出存储桶中的文件（使用 `--recursive` 递归进入子目录）。

**rm**
> 删除匹配某个 `b2://` 路径的文件。

**sync**
> 在本地目录和存储桶之间同步（单向）。

**key create**
> 创建有作用域限制的应用密钥。

**--threads** _num_
> 操作使用的并行线程数。

**--no-progress**
> 禁用进度显示。

# FEATURES

- 大文件支持（最大 10 TB）
- 文件版本控制
- 服务器端加密
- 生命周期规则
- 兼容 S3 的 API
- 增量同步

# WORKFLOW

```bash
# Authorize
b2 account authorize <keyId> <key>

# Create bucket
b2 bucket create myBucket allPrivate

# Upload directory
b2 sync /local/path b2://myBucket/remote/path

# Download
b2 sync b2://myBucket/path /local/path
```

# CAVEATS

需要具备相应权限的应用密钥。下载会产生带宽费用。已删除的文件可能仍会被保留（版本控制）。Class C 事务需要付费。首次运行同步操作可能较慢。

# HISTORY

**B2 CLI** 由 Backblaze 于 **2015** 年前后随 B2 Cloud Storage 服务一同发布，作为 Amazon S3 的低价替代方案。

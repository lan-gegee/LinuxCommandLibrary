# TAGLINE

终端取色器

# TLDR

**启动交互式取色器**

```termpicker```

# SYNOPSIS

**termpicker** [_options_]

# DESCRIPTION

**termpicker** 是一个为真彩色终端设计的简单取色器。它让你通过 RGB、HSL 和 CMYK 滑块创建颜色，在颜色格式之间无缝转换，并以 RGB、HEX、HSL、CMYK 和 ANSI 真彩色等格式将结果复制到剪贴板。

快捷键会显示在界面中，按 **?** 键可展开其说明。

# CAVEATS

需要支持真彩色的终端。剪贴板复制依赖系统剪贴板集成。

# DESCRIPTION

**omega** 是诞生于 **20 世纪 80 年代**的一款复杂 Roguelike RPG，同时包含地下城探险和城镇探索。与大多数 Roguelike 不同，这款游戏拥有一个持久的开放世界，其中的城镇包含公会、神庙、商店等场所。

游戏提供多条通往胜利的路径：战斗、魔法或外交。角色可以加入公会、信奉神明并接受任务。移动使用 hjklyubn 键。

# CAVEATS

极其复杂，键盘命令繁多。存在永久死亡机制。即使对 Roguelike 老手来说，学习曲线也很陡峭。

# HISTORY

**omega** 由 **Laurence Brothers** 自 **1987** 年起编写。它是那个时代最具野心的 Roguelike 游戏之一，规模远超典型的地下城爬行类游戏。

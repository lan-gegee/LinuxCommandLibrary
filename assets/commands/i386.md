# TAGLINE

以 32 位 x86（i386）personality 运行程序——**setarch i386** 的别名

# TLDR

此命令是 **setarch i386** 的别名。参见：

```tldr setarch```

在 i386 personality 下**运行一个 shell**

```i386```

在 i386 personality 下**运行一条命令**

```i386 [command] [args]```

向子进程**报告 i386 的 uname**

```i386 uname -m```

在子进程中**禁用地址空间布局随机化**

```i386 -R [command]```

# SYNOPSIS

**i386** [_options_] [_program_ [_arguments_]]

# DESCRIPTION

**i386** 是 `setarch i386` 的便捷名称——它会调整子进程的 Linux personality，使 `uname -m` 报告为 `i386`，并让地址布局方面的行为与 32 位 x86 系统一致。它**不会**安装 32 位库，也不能运行非本机架构的二进制文件；它只改变内核报告架构的方式，并可选择禁用 ASLR、READ_IMPLIES_EXEC 等标志。

不带参数时，`i386` 会在修改后的 personality 下启动 `$SHELL`。`setarch` 接受的所有标志（`-R` 禁用 ASLR、`-F` FDPIC_FUNCPTRS、`-Z` MMAP_PAGE_ZERO、`-L` ADDR_COMPAT_LAYOUT、`-X` READ_IMPLIES_EXEC、`-B` ADDR_NO_RANDOMIZE 等）在这里同样适用。

# CAVEATS

只改变所报告的架构和 personality 标志——它**不能**让 64 位内核凭自身运行 32 位二进制文件；你仍然需要 32 位 multiarch/multilib 支持。某些发行版不再提供 `i386` 符号链接；若缺少该快捷方式，请直接使用 `setarch i386`。

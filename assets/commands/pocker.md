# TAGLINE

用于 Docker 容器管理的 TUI 工具

# TLDR

**启动 Docker TUI**

```pocker```

# SYNOPSIS

**pocker** [_options_]

# DESCRIPTION

**pocker** 是一个用于管理 Docker 容器的终端用户界面。它可以显示容器、镜像、日志、属性、环境变量以及容器统计信息。它基于 docker-py 和 Textual 构建，为常见的 Docker 操作提供键盘驱动的界面。

# CAVEATS

需要已安装并正在运行的 Docker。

# HISTORY

**pocker** 由 **pommee** 创建，使用 **Python** 编写。

# TAGLINE

演示 Muffin 窗口类型

# TLDR

**运行窗口演示**

```muffin-window-demo```

**演示特定窗口类型**

```muffin-window-demo --type=[dialog]```

# SYNOPSIS

**muffin-window-demo** [_options_]

# PARAMETERS

**--type** _TYPE_
> 要演示的窗口类型。

**--help**
> 显示帮助信息。

# DESCRIPTION

**muffin-window-demo** 演示 Muffin 的窗口类型，展示不同的窗口装饰。

该工具显示示例窗口，用于测试和主题开发。

# CAVEATS

开发工具。仅适用于 Cinnamon/Muffin。用于测试窗口装饰。

# HISTORY

muffin-window-demo 是 **Muffin** 开发工具的一部分，用于测试窗口管理器行为。

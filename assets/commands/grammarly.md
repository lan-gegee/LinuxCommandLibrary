# TAGLINE

AI 驱动的写作助手

# TLDR

**使用 Grammarly 浏览器扩展**

```Install from browser extension store```

**使用 Grammarly 桌面版**

```grammarly```

# DESCRIPTION

**Grammarly** 是一款写作助手，可以检查语法、拼写、标点和文风。它主要通过浏览器扩展、桌面应用程序以及与文本编辑器的集成来使用。

Grammarly 在你写作时提供实时建议，付费功能包括语气检测、清晰度改进和抄袭检查。

# PLATFORMS

- 浏览器扩展（Chrome、Firefox、Safari、Edge）
- 桌面应用（Windows、macOS）
- 移动键盘（iOS、Android）
- Microsoft Office 集成
- Google Docs 插件

# FEATURES

**免费版：**
- 语法和拼写
- 标点符号
- 精简表达

**付费版：**
- 清晰度与吸引力
- 用词选择
- 语气检测
- 抄袭检测
- 专家写作协助

# CAVEATS

完整功能需要订阅。会将文本发送到云端进行分析。处理敏感文档时需考虑隐私问题。没有官方 Linux 桌面应用。

# HISTORY

Grammarly 由 **Alex Shevchenko**、**Max Lytvyn** 和 **Dmytro Lider** 于 **2009 年**在乌克兰基辅创立。它已发展为服务数百万用户的产品，成为最受欢迎的写作辅助工具之一。

# TAGLINE

支持插件的后现代终端文件管理器

# TLDR

**在当前目录打开文件管理器**

```rovr```

**在指定路径打开文件管理器**

```rovr [/home/user/projects]```

# SYNOPSIS

**rovr** [_path_]

# DESCRIPTION

**rovr** 是一个现代化的终端文件浏览器，具有多标签页浏览、内置文件预览（支持 sixel），以及可集成 zoxide、bat、fd 和 ripgrep 等工具的插件系统。它还具备剪贴板管理、排序、上下文菜单以及可自定义的主题和快捷键。

# HISTORY

**rovr** 由 **NSPC911** 创建，使用 **Python** 和 Textual 库编写。

```aur: yay -S rovr```

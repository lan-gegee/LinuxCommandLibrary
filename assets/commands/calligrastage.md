# TAGLINE

Calligra 套件中的演示文稿应用

# TLDR

**启动 Calligra Stage**

```calligrastage```

**打开**演示文稿文件

```calligrastage [presentation.odp]```

**显示版本信息**

```calligrastage --version```

**显示所有可用选项**

```calligrastage --help-all```

# SYNOPSIS

**calligrastage** [_options_] [_file_]

# PARAMETERS

**--help**
> 显示选项相关的帮助。

**--help-qt**
> 显示 Qt 特有选项。

**--help-kde**
> 显示 KDE 特有选项。

**--help-all**
> 显示所有选项。

**--author**
> 显示作者信息。

**-v**, **--version**
> 显示版本信息。

**--license**
> 显示许可证信息。

# DESCRIPTION

**calligrastage** 是 Calligra 办公套件中的演示文稿应用。它用于创建和展示幻灯片演示，支持切换效果、动画和多媒体。

该应用使用 ODF（开放文档格式），可与 Microsoft PowerPoint 或 LibreOffice Impress 相媲美。

# INSTALL

```apt: sudo apt install calligrastage```

```dnf: sudo dnf install calligra```

```pacman: sudo pacman -S calligra```

```apk: sudo apk add calligra```

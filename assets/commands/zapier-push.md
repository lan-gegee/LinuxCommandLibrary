# TAGLINE

将集成部署到 Zapier

# TLDR

**推送集成**

```zapier push```

# SYNOPSIS

**zapier** **push**

# DESCRIPTION

**zapier push** 将你的集成部署到 Zapier，上传已构建的集成并创建新版本。可在 zapier build 之后运行，或让 push 自动构建。

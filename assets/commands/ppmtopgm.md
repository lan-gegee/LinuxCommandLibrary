# TAGLINE

将彩色 PPM 图像转换为灰度

# TLDR

**将彩色转换为灰度**

```ppmtopgm [input.ppm] > [output.pgm]```

# SYNOPSIS

**ppmtopgm** [_file_]

# DESCRIPTION

**ppmtopgm** 将 PPM 彩色图像转换为 PGM 灰度图像。使用标准光度公式计算灰度值。属于 Netpbm 工具集。

```dnf: sudo dnf install netpbm```

```pacman: sudo pacman -S netpbm```

```apk: sudo apk add netpbm```

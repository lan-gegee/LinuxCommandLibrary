# TAGLINE

快速的免费控制台 MPEG 音频播放器，支持 layer 1、2、3

# TLDR

**播放** MP3 文件

```mpg123 [path/to/file1.mp3] [path/to/file2.mp3]```

从 **stdin** 播放 MP3

```cat [file.mp3] | mpg123 -```

以**随机顺序**播放

```mpg123 -z [path/to/*.mp3]```

**循环**播放

```mpg123 --loop [3] [path/to/file.mp3]```

输出到 **WAV 文件**

```mpg123 -w [output.wav] [input.mp3]```

从 **URL** 播放

```mpg123 [http://example.com/stream.mp3]```

# INTERACTIVE CONTROLS

**f** - 快进到下一首
**b** - 回到歌曲开头
**s** - 停止/重播当前文件
**.** - 快进
**,** - 快退
**+/-** - 增大/减小音量
**q** - 退出

# SYNOPSIS

**mpg123** [_options_] _file-or-URL_...

# PARAMETERS

**-o, --output _module_**
> 选择音频输出模块

**-a, --audiodevice _device_**
> 指定音频设备

**-w, --wav _file_**
> 将输出写入 WAV 文件

**-s, --stdout**
> 将原始音频写入 stdout

**-r, --rate _rate_**
> 设置采样率

**-m, --mono**
> 解码为单声道

**-z, --shuffle**
> 随机打乱播放列表

**-Z, --random**
> 持续随机播放

**--loop _count_**
> 重复播放 count 次

**-@, --list _file_**
> 从文件读取播放列表

**-k _frames_**
> 跳过开头的若干帧

**-n _frames_**
> 仅解码指定数量的帧

**-C, --control**
> 启用终端控制按键

**-q, --quiet**
> 不显示输出消息

**-v, --verbose**
> 提高详细程度

**-t, --test**
> 测试解码，不输出音频

**-b, --buffer _size_**
> 音频缓冲区大小（KB）

**-E, --equalizer _file_**
> 从文件应用 32 段均衡器

**-2, --2to1**
> 以 2:1 比例降采样（输出采样率减半）。

**-4, --4to1**
> 以 4:1 比例降采样。

**-g, --gain _value_**
> 设置音频硬件输出增益。

**-f, --scale _factor_**
> 设置输出样本的缩放因子（音量）。

**--au _file_**
> 将输出写为 Sun AU 文件。

**--cdr _file_**
> 将输出写为原始 CDR 文件。

# DESCRIPTION

**mpg123** 是一个快速、免费的控制台 MPEG 音频播放器，支持 layer 1、2 和 3。它可以播放本地文件、从 stdin 读取数据以及从 HTTP URL 流式播放。该播放器支持多种音频输出模块，包括 ALSA、PulseAudio 和 OSS。

终端控制模式（-C）支持交互式播放控制，可通过键盘命令进行跳转、音量调节和曲目切换。

# CAVEATS

MPEG 音频解码比较消耗 CPU，layer 3 尤其如此。网络串流需要带宽达到或超过音频比特率。自 1.26.0 版本起，任何曲目解析失败都会返回非零退出码。

# HISTORY

**mpg123** 由 **Michael Hipp** 于 20 世纪 90 年代中期编写，此后持续开发。它仍然是类 Unix 系统上最高效的控制台 MP3 播放器之一。

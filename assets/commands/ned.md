# TAGLINE

文本编辑器

# TLDR

**编辑文件**

```ned [file.txt]```

**编辑多个文件**

```ned [file1.txt] [file2.txt]```

**只读模式**

```ned -R [file.txt]```

# SYNOPSIS

**ned** [_options_] [_files_]

# PARAMETERS

_FILES_
> 要编辑的文件。

**-R**
> 只读模式。

**--help**
> 显示帮助信息。

# DESCRIPTION

**ned** 是一款文本编辑器。它提供简单的文本编辑功能。

该工具是一个极简编辑器。具备快速修改所需的基本功能。

# CAVEATS

功能极少。不如 nano/vim 常见。使用前请确认已安装。

# HISTORY

ned 是可用于命令行文本编辑的多款**简单文本编辑器**之一。

# INSTALL

```aur: yay -S ned```

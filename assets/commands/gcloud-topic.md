# TAGLINE

显示补充帮助主题

# TLDR

**列出可用主题**

```gcloud topic```

**查看特定主题**

```gcloud topic [configurations]```

**查看 auth 主题**

```gcloud topic [auth]```

**查看 formats 主题**

```gcloud topic [formats]```

# SYNOPSIS

**gcloud** **topic** [_topic_]

# TOPICS

**configurations**
> 命名配置。

**auth**
> 身份验证信息。

**formats**
> 输出格式。

**filters**
> 过滤表达式。

**projections**
> 资源投影。

**escaping**
> 转义与引号处理。

**startup**
> SDK 启动。

# DESCRIPTION

**gcloud topic** 显示 gcloud 命令的补充帮助主题。这些主题提供有关各种 gcloud 概念和特性的详细信息。

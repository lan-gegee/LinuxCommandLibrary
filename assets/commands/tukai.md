# TAGLINE

基于终端的触打字练习应用

# TLDR

**开始一次打字练习**

```tukai```

# SYNOPSIS

**tukai** [_options_]

# KEYBOARD CONTROLS

**Ctrl+C** / **Esc**
> 退出应用。

**Ctrl+R**
> 重启并生成新文本。

**Ctrl+S**
> 切换模板。

**Ctrl+P**
> 切换语言。

**Ctrl+T**
> 切换透明背景。

**Ctrl+H** / **Left arrow**
> 向后切换屏幕。

**Ctrl+L** / **Right arrow**
> 向前切换屏幕。

# DESCRIPTION

**tukai** 是一个用 **Ratatui** 构建的极简终端触打字练习工具。它提供交互式打字练习，支持可切换的模板、内置统计跟踪、多语言支持，以及实时的速度和准确率反馈。

# HISTORY

**tukai** 由 **hlsxx** 创建，用 **Rust** 编写。

# INSTALL

```pacman: sudo pacman -S tukai```

```nix: nix profile install nixpkgs#tukai```

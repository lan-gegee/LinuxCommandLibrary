# TAGLINE

检查 Sailfish OS 项目中的问题

# TLDR

**检查项目中的问题**

```sfdk check```

**检查特定方面**

```sfdk check --rpmlint```

# SYNOPSIS

**sfdk check** [_options_]

# PARAMETERS

**--rpmlint**
> 运行 rpmlint 检查。

# DESCRIPTION

**sfdk check** 检查 Sailfish OS 项目中的常见问题、打包错误和合规性。属于 Sailfish SDK 的一部分。

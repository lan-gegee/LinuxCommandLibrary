# TAGLINE

检查已安装软件包的依赖兼容性

# TLDR

**检查损坏的依赖关系**

```pip check```

# SYNOPSIS

**pip** **check**

# DESCRIPTION

**pip check** 用于验证已安装的软件包是否具有兼容的依赖，并报告任何缺失或冲突的要求。适用于诊断 Python 环境中的依赖问题。

# INSTALL

```apk: sudo apk add py3-pip```

# TAGLINE

终端数字时钟

# TLDR

**显示居中时钟**并带秒数

```tty-clock -c -s```

**以 12 小时制显示**并使用粗体

```tty-clock -t -b```

**显示边框**并使用绿色

```tty-clock -x -C 2```

**显示 UTC 时间**并自定义日期格式

```tty-clock -u -f "[%A %d %B]"```

**以屏幕保护模式显示**（按键即退出）

```tty-clock -S -c -s```

**显示弹跳动画**并让冒号闪烁

```tty-clock -r -B```

# SYNOPSIS

**tty-clock** [**-iuvsScbtrahDBxn**] [**-C** _0-7_] [**-f** _format_] [**-d** _delay_] [**-a** _nsdelay_] [**-T** _tty_]

# PARAMETERS

**-s**
> 显示秒数。

**-S**
> 屏幕保护模式；首次按键即退出。

**-x**
> 在时钟周围显示方框。

**-c**
> 将时钟居中显示在终端上。

**-C** _0-7_
> 设置时钟颜色（0=黑、1=红、2=绿、3=黄、4=蓝、5=品红、6=青、7=白）。

**-b**
> 启用粗体。

**-t**
> 使用 12 小时制（AM/PM）时间格式。

**-u**
> 显示 UTC 时间。

**-T** _tty_
> 在指定的终端设备上显示时钟。

**-r**
> 启用弹跳动画；时钟在终端边缘弹跳。

**-f** _format_
> 自定义日期格式字符串（遵循 **strftime**(3)）。

**-n**
> 按键不退出；必须通过信号终止。

**-D**
> 隐藏日期显示。

**-B**
> 启用冒号分隔符闪烁。

**-d** _delay_
> 设置重绘延迟秒数（默认：1）。

**-a** _nsdelay_
> 重绘之间额外的纳秒延迟。

**-i**
> 显示时钟信息（版本、编译选项）。

**-v**
> 显示版本信息。

**-h**
> 显示帮助文本。

# DESCRIPTION

**tty-clock** 是一个基于 ncurses 库构建的终端数字时钟。它直接在终端中以大号块状数字渲染当前时间，可选择在下方显示日期。时钟支持多种显示模式，包括居中、弹跳动画、屏幕保护模式和自定义颜色。

运行期间，时钟会响应键盘命令：**K/J/H/L** 进行 vi 风格的移动定位，**0-7** 更改颜色，**B** 切换粗体，**X** 切换边框，**C** 居中，**R** 弹跳模式，**S** 切换秒数显示，**T** 切换 12 小时制，**Q** 退出。

# CAVEATS

**-C** 颜色选项只支持终端基本的 8 色调色板。使用 **-c** 居中后会禁用 vi 风格移动命令。使用 **-n** 模式时，由于按键退出被禁用，必须通过信号终止进程。需要安装 **libncurses**。

# HISTORY

**tty-clock** 由 **Martin Duquesnoy**（xorg62）于 **2008 年**创建，是一个用 C 编写的轻量级终端时钟工具。此后该项目由社区维护，多年来的贡献改进了信号处理、区域语言兼容性和 ncurses 支持。

# TAGLINE

列出 Zapier 集成的各个版本

# TLDR

**列出版本**

```zapier versions```

# SYNOPSIS

**zapier** **versions**

# DESCRIPTION

**zapier versions** 显示你的 Zapier 集成的所有版本，包括版本号和部署状态。适合跟踪发布和回滚。

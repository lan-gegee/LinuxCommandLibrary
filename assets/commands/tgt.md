# TAGLINE

Telegram 的 TUI 客户端

# TLDR

**启动 Telegram TUI**

```tgt```

# SYNOPSIS

**tgt** [_options_]

# DESCRIPTION

**tgt** 是 Telegram 的终端用户界面，让你完全在终端中收发、编辑、删除和回复消息。它支持通过 TOML 配置文件自定义主题和快捷键，提供完整的键盘导航，并支持查看图片。

# HISTORY

**tgt** 由 **Federico Bruzzone** 创建，使用 **Rust** 编写。

# INSTALL

```apt: sudo apt install tcm```

```pacman: sudo pacman -S tgt```

```zypper: sudo zypper install tgt```

```nix: nix profile install nixpkgs#tgt```

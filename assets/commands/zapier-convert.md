# TAGLINE

将旧版 Zapier 集成转换为 CLI 格式

# TLDR

**转换旧版集成**

```zapier convert [app_id] [path]```

**指定版本进行转换**

```zapier convert [app_id] [path] --version [version]```

# SYNOPSIS

**zapier** **convert** _app_id_ _path_ [_options_]

# PARAMETERS

**--version** _version_
> 要转换的特定版本。

# DESCRIPTION

**zapier convert** 将旧版 Web Builder 集成迁移为 CLI 格式，把可视化集成转换为基于代码的项目，便于高级开发。

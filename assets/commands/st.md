# TLDR

此命令可能指代不同的工具。请参阅以下文档：

**st (terminal emulator)**

```tldr st.1```

# DESCRIPTION

命令 **st** 最常指的是来自 suckless.org 项目的 X11 简约终端模拟器。其文档见 **st.1**。

名称 **st** 也被一些无关的命令行统计工具用于分析数值数据，但那些是独立的、较少见的工具。

# INSTALL

```apt: sudo apt install stterm```

```dnf: sudo dnf install st```

```apk: sudo apk add st```

```zypper: sudo zypper install st```

```brew: brew install st```

```nix: nix profile install nixpkgs#st```

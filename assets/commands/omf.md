# TAGLINE

oh My Fish，一个 Fish Shell 框架

# TLDR

**安装包**

```omf install [package]```

**列出已安装的包**

```omf list```

**更新 Oh My Fish**

```omf update```

**搜索包**

```omf search [query]```

**卸载包**

```omf remove [package]```

**更换主题**

```omf theme [theme_name]```

# SYNOPSIS

**omf** [_command_] [_options_]

# PARAMETERS

**install** _PACKAGE_
> 安装包/主题。

**list**
> 列出已安装的包。

**update**
> 更新框架。

**search** _QUERY_
> 搜索包。

**remove** _PACKAGE_
> 卸载包。

**theme** _NAME_
> 更换主题。

**--help**
> 显示帮助信息。

# DESCRIPTION

**omf** 即 Oh My Fish，是一个 Fish Shell 框架，用于管理插件和主题。

该工具扩展 Fish Shell 的功能，拥有社区驱动的包生态。

# CAVEATS

需要 Fish Shell。属于社区包体系。可能与其他框架冲突。

# HISTORY

Oh My Fish 作为 Fish Shell 的**包管理器**而创建。

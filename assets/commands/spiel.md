# TAGLINE

用 Python 制作富样式的终端演示文稿

# TLDR

**查看内置演示文稿**

```spiel demo present```

**演示自定义幻灯片文件**

```python [deck.py]```

# SYNOPSIS

**spiel** _command_ [_options_]

# DESCRIPTION

**spiel** 是一个 Python 框架，基于 Rich 库在终端中构建和呈现富样式的幻灯片。幻灯片通过 Python 装饰器以编程方式定义，支持图片、动画、自定义转场效果，以及在编辑期间实时重载的 watch 模式。

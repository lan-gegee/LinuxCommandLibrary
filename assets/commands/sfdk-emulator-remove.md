# TAGLINE

移除已安装的 Sailfish OS 模拟器

# TLDR

**移除模拟器**

```sfdk emulator remove [emulator_name]```

# SYNOPSIS

**sfdk emulator remove** _name_ [_options_]

# DESCRIPTION

**sfdk emulator remove** 移除已安装的 Sailfish OS 模拟器。属于 Sailfish SDK 的一部分。

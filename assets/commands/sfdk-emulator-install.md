# TAGLINE

安装 Sailfish OS 模拟器镜像

# TLDR

**安装模拟器**

```sfdk emulator install [emulator_name]```

# SYNOPSIS

**sfdk emulator install** _name_ [_options_]

# DESCRIPTION

**sfdk emulator install** 安装新的 Sailfish OS 模拟器镜像。属于 Sailfish SDK 的一部分。

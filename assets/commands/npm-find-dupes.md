# TAGLINE

搜索 node_modules 中的重复软件包

# TLDR

**查找重复的软件包**

```npm find-dupes```

# SYNOPSIS

**npm** **find-dupes**

# DESCRIPTION

**npm find-dupes** 搜索 node_modules 中的重复软件包，报告以不同版本被多次安装的软件包。可使用 npm dedupe 来消除重复。

# INSTALL

```pacman: sudo pacman -S npm```

```apk: sudo apk add npm```

```brew: brew install npm```

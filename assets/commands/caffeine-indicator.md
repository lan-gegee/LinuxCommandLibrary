# TAGLINE

系统托盘开关，用于阻止空闲休眠

# TLDR

启动 **caffeine indicator** 小程序

```caffeine-indicator```

# SYNOPSIS

**caffeine-indicator**

# DESCRIPTION

**caffeine-indicator** 提供一个系统托盘指示器，可手动控制桌面空闲抑制。点击该指示器即可切换是否阻止屏幕保护程序、挂起及其他空闲动作。

与自动工作的 caffeine 守护进程不同，它提供的是手动开关控制。

# INSTALL

```zypper: sudo zypper install caffeine```

```nix: nix profile install nixpkgs#caffeine```

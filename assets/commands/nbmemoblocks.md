# TAGLINE

终端记忆配对游戏

# TLDR

**玩记忆翻牌游戏**

```nbmemoblocks```

**以指定难度开始**

```nbmemoblocks -d [easy]```

# SYNOPSIS

**nbmemoblocks** [_options_]

# PARAMETERS

**-d** _LEVEL_
> 难度等级。

**--help**
> 显示帮助信息。

# DESCRIPTION

**nbmemoblocks** 是一款终端记忆配对游戏。找出并配对相同的方块。

该工具可锻炼记忆力。使用 ncurses 界面。

# CAVEATS

基于终端的游戏。属于游戏合集。使用键盘导航。

# HISTORY

nbmemoblocks 是经典记忆卡片配对游戏的**终端实现**。

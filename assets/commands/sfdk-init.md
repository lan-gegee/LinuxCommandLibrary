# TAGLINE

初始化新的 Sailfish OS 项目

# TLDR

**初始化新的 QML 应用项目**

```sfdk init --type qtquick2-app```

**以指定名称初始化项目**

```sfdk init --type qtquick2-app --name [myapp]```

**列出可用项目模板**

```sfdk init --help```

# SYNOPSIS

**sfdk init** [_options_]

# PARAMETERS

**--type** _type_, **-t** _type_
> 项目模板类型（例如 qtquick2-app）。

**--name** _name_
> 项目名称。

# DESCRIPTION

**sfdk init** 从模板初始化新的 Sailfish OS 项目。属于 Sailfish SDK 命令行工具的一部分。

# TAGLINE

终端播客管理器和播放器

# TLDR

**启动播客播放器**

```podliner```

# SYNOPSIS

**podliner** [_options_]

# DESCRIPTION

**podliner** 是一个基于终端的播客管理器和播放器。它支持搜索和订阅播客、队列管理、播放速度控制、gPodder API 同步以及 OPML 导入/导出。音频播放使用可配置的引擎，包括 mpv、ffplay、VLC 或 Media Foundation。导航采用 vim 风格的按键绑定。

# HISTORY

**podliner** 由 **Tim Kicker**（timkicker）创建，使用 **Rust** 编写。

# TAGLINE

即时的系统信息快照

# TLDR

**显示系统信息**

```zeitfetch```

**不显示 ASCII 艺术标志**

```zeitfetch --no-logo```

**以极简垂直布局显示**

```zeitfetch --minimal```

# SYNOPSIS

**zeitfetch** [_options_]

# DESCRIPTION

**zeitfetch** 是一款类似 neofetch 的系统信息工具，力求近乎瞬时完成且依赖极少。它显示操作系统、内核、运行时间、Shell 和硬件信息，并带有 ASCII 艺术标志。完全跨平台，支持 Windows、macOS 和 Linux。

# HISTORY

**zeitfetch** 由 **Henrique**（nidnogg）创建，使用 **Rust** 编写。

# INSTALL

```dnf: sudo dnf install zeitfetch```

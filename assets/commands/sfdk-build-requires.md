# TAGLINE

管理 Sailfish OS 构建依赖

# TLDR

**列出构建依赖**

```sfdk build-requires```

**安装缺失的依赖**

```sfdk build-requires --install```

# SYNOPSIS

**sfdk build-requires** [_options_]

# PARAMETERS

**--install**
> 安装缺失的依赖。

**--target** _name_
> 构建目标。

# DESCRIPTION

**sfdk build-requires** 管理 Sailfish OS 项目的构建依赖，列出并安装所需的软件包。属于 Sailfish SDK 的一部分。

# TAGLINE

通过 NetworkManager TUI 设置系统主机名

# TLDR

该命令是 [nmtui](/man/nmtui) 的别名。

**直接启动主机名编辑器**

```nmtui-hostname```

# INSTALL

```apt: sudo apt install network-manager```

```apk: sudo apk add networkmanager-tui```

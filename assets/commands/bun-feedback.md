# TAGLINE

在浏览器中打开反馈页面

# TLDR

**打开 Bun 的反馈页面**

```bun feedback```

# SYNOPSIS

**bun** **feedback**

# DESCRIPTION

**bun feedback** 在默认浏览器中打开 Bun 反馈页面，你可以在此向 Bun 开发团队提交 bug 报告、功能请求或一般性反馈。

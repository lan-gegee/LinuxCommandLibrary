# TAGLINE

显示 crane 的版本信息

# TLDR

**查看 crane 版本**

```crane version```

# SYNOPSIS

**crane** **version**

# DESCRIPTION

**crane version** 显示 crane CLI 工具的版本信息。Crane 是一个用于与远程容器镜像和镜像仓库交互的工具，属于 google/go-containerregistry 项目。

# INSTALL

```pacman: sudo pacman -S crane```

```apk: sudo apk add crane```

```zypper: sudo zypper install crane```

```brew: brew install crane```

```nix: nix profile install nixpkgs#crane```

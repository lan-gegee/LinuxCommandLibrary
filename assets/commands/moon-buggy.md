# TAGLINE

终端小游戏

# TLDR

**开始游戏**

```moon-buggy```

**显示高分榜**

```moon-buggy -s```

**静音游玩**

```moon-buggy -n```

**显示版本**

```moon-buggy -V```

# SYNOPSIS

**moon-buggy** [_options_]

# PARAMETERS

**-s**
> 显示高分榜。

**-n**
> 禁用音效。

**-V**
> 显示版本。

**--help**
> 显示帮助信息。

# DESCRIPTION

**moon-buggy** 是一个终端小游戏。驾驶月球车穿越月球表面，跳过一个个环形山。

这是一款简单的街机游戏。用空格键跳跃，用控制键躲避障碍。

# CAVEATS

终端游戏。需要 ncurses。高分保存在本地。

# HISTORY

moon-buggy 的创作灵感来自经典的月面巡逻风格街机游戏，是一款**控制台游戏**。

# INSTALL

```dnf: sudo dnf install moon-buggy```

```brew: brew install moon-buggy```

```nix: nix profile install nixpkgs#moon-buggy```

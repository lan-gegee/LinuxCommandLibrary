# TAGLINE

将 PPM 转换为 Apple 卷标格式

# TLDR

**将 PPM 转换为 Apple 卷标**

```ppmtoapplevol [input.ppm] > [output.vol]```

# SYNOPSIS

**ppmtoapplevol** [_file_]

# DESCRIPTION

**ppmtoapplevol** 将 PPM 图像转换为 Apple 卷标格式，用于 Macintosh 上的自定义磁盘图标。属于 Netpbm 工具集。

```apk: sudo apk add netpbm```

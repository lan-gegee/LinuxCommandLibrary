# TAGLINE

powerlevel10k 配置工具

# TLDR

**运行配置向导**

```p10k configure```

**无需重启 Shell 即可重新加载配置**

```p10k reload```

**显示帮助信息**

```p10k help```

# SYNOPSIS

**p10k** [_command_]

# PARAMETERS

**configure**
> 运行交互式设置向导，自定义提示符外观。

**reload**
> 不重启 Shell 而重新加载 Powerlevel10k 配置。

**help**
> 显示帮助信息。

# DESCRIPTION

**p10k** 是 Powerlevel10k 的配置工具，后者是一款快速而灵活的 Zsh 提示符主题。

**configure** 命令启动交互式向导，用于自定义提示符样式、图标和分段。**reload** 命令在不重启 Shell 的情况下应用对 **~/.p10k.zsh** 的修改。Powerlevel10k 在初始化后支持 POWERLEVEL9K 选项的热重载。

# CAVEATS

需要安装 Powerlevel10k。仅支持 Zsh。推荐使用 Nerd Fonts。

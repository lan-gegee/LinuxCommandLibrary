# TAGLINE

Void Linux 包管理系统

# TLDR

查看 **install** 文档

```tldr xbps-install```

查看 **remove** 文档

```tldr xbps-remove```

查看 **query** 文档

```tldr xbps-query```

# DESCRIPTION

**xbps**（X Binary Package System）是 Void Linux 所用的包管理器。它不是单个命令，而是一组用于软件包管理的相关命令。

主要命令包括用于安装/更新的 xbps-install、用于移除的 xbps-remove，以及用于查询软件包信息的 xbps-query。

# CAVEATS

Void Linux 专用。命令语法与其他包管理器不同。

# INSTALL

```nix: nix profile install nixpkgs#xbps```

# TAGLINE

纸牌游戏 Mille Bornes（千里牌）

# TLDR

**玩 Mille Bornes 游戏**

```mille```

**从文件恢复已保存的游戏**

```mille [path/to/savefile]```

# SYNOPSIS

**mille** [_file_]

# PARAMETERS

_file_
> 要恢复的存档文件。

# PREVIEW

```
 HAND: [Go] [25] [75]
 MILES: 425 / 1000
 SAFETY: [Right of Way]
```

# DESCRIPTION

**mille** 让你与计算机进行双人 Mille Bornes 纸牌对战。玩家竞相率先跑满 1000 英里，同时向对手打出危害牌，并使用补救牌和安全牌应对。

游戏中，你可以从牌堆抽牌、输入牌的编号来出牌或弃牌、切换手牌排序方式、按 'S' 保存游戏，或用 Ctrl-L 重绘屏幕。

属于 **bsdgames** 软件包。

# CAVEATS

属于 bsdgames。基于终端。游戏界面使用文本化的卡牌显示和键盘控制。

# HISTORY

mille 是 **bsdgames** 的一部分，实现了法国纸牌游戏 Mille Bornes（1954 年）。原始代码由 Ken Arnold 编写。

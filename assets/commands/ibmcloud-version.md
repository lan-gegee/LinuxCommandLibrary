# TAGLINE

显示 IBM Cloud CLI 版本

# TLDR

**显示版本**

```ibmcloud version```

**显示详细信息**

```ibmcloud version --all```

# SYNOPSIS

**ibmcloud version** [_options_]

# PARAMETERS

**--all**
> 显示所有版本信息。

**--help**
> 显示帮助信息。

# DESCRIPTION

**ibmcloud version** 显示 IBM Cloud CLI 的版本。它会展示已安装的 CLI 版本和 SDK 信息。

该命令有助于验证安装情况并检查更新。提交问题前可先使用。

# CAVEATS

简单的信息查询命令。更新需另行检查。属于 ibmcloud CLI 的一部分。

# HISTORY

ibmcloud version 是 **IBM Cloud** CLI 的一部分。

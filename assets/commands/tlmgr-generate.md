# TAGLINE

重新生成 TeX Live 配置文件

# TLDR

**重新生成配置文件**

```tlmgr generate updmap```

**重新生成语言文件**

```tlmgr generate language```

**重新生成字体映射**

```tlmgr generate fmtutil```

# SYNOPSIS

**tlmgr generate** _config_

# PARAMETERS

**updmap**
> 重新生成字体映射配置。

**language**
> 重新生成 language.dat 文件。

**fmtutil**
> 重新生成格式配置。

# DESCRIPTION

**tlmgr generate** 重新生成 TeX Live 配置文件。重建字体映射、格式文件和语言连字符断字模式。TeX Live Manager 的维护功能之一。

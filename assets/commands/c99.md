# TAGLINE

POSIX 标准的 C99 编译器接口

# TLDR

**将 C 源文件编译为可执行文件**

```c99 [file.c] -o [output]```

**只编译不链接（生成目标文件）**

```c99 -c [file.c]```

**链接库进行编译**

```c99 [file.c] -l[library] -o [output]```

**定义预处理器宏**

```c99 -D [NAME=value] [file.c] -o [output]```

**添加头文件包含目录**

```c99 -I [path/to/includes] [file.c] -o [output]```

**开启优化编译**

```c99 -O [file.c] -o [output]```

# SYNOPSIS

**c99** [**-c**] [**-D** _name_[=_value_]...] [**-E**] [**-g**] [**-I** _directory_...] [**-L** _directory_...] [**-o** _outfile_] [**-O** _optlevel_] [**-s**] [**-U** _name_...] _operand..._

# DESCRIPTION

**c99** 是 C 编译系统的 POSIX 标准接口，用于编译符合 C99 的源代码。它编译 C 源文件并链接生成可执行文件，也可以只生成目标文件供以后链接。

该命令接受源文件（**.c**）、目标文件（**.o**）和库归档（**.a**）作为操作数。不使用 **-o** 选项时，可执行文件写入 **a.out**。

# PARAMETERS

**-c**
> 只编译不链接，生成目标文件（.o）

**-D** _name_[=_value_]
> 定义预处理器宏

**-E**
> 只做预处理，不编译

**-g**
> 包含调试信息

**-I** _directory_
> 将目录加入头文件搜索路径

**-L** _directory_
> 将目录加入库搜索路径

**-l** _library_
> 链接指定的库

**-o** _outfile_
> 将输出写入指定文件

**-O** _optlevel_
> 启用优化（0、1、2、3）

**-s**
> 从输出中剥离符号

**-U** _name_
> 取消预处理器宏定义

# CAVEATS

**c99** 命令并非在所有系统上都可用；只有提供 POSIX C 语言开发选项的系统才要求提供它。在 Linux 上，它通常会以适当的标志调用 **gcc** 或 **clang** 以符合 C99 标准。

# HISTORY

**c99** 工具随 **IEEE Std 1003.1-2001**（POSIX.1-2001）引入，基于 ISO POSIX-2:1993 中更早的 **c89** 工具。它反映了为支持 **ISO/IEC 9899:1999** C 标准（C99）所做的更新。

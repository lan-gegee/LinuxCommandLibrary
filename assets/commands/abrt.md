# TAGLINE

自动错误报告工具的别名

# TLDR

此命令是 abrt-cli 的**别名**

查看原始命令的文档

```tldr abrt-cli```

# SYNOPSIS

**abrt**

# DESCRIPTION

**abrt** 是 **abrt-cli** 的别名，后者是 Automatic Bug Reporting Tool（自动错误报告工具）的命令行界面。完整文档参见 **abrt-cli**。

# INSTALL

```dnf: sudo dnf install abrt```

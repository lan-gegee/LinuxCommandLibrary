# TAGLINE

受 Lotus 1-2-3 启发的现代终端电子表格

# TLDR

在空白工作簿中**启动**电子表格

```l123```

**打开现有工作簿**

```l123 [path/to/financials.xlsx]```

**显示当前设置**

```l123 config```

**创建示例配置文件**

```l123 config --init```

在应用内**打开斜杠菜单**

```/```

# SYNOPSIS

**l123** [_file_]

**l123** **config** [**--init**]

# PARAMETERS

**config**
> 显示当前生效的配置。配合 **--init** 时，将一份示例配置文件写入磁盘。

**--init**
> 与 **config** 配合使用，创建一份初始配置文件。

# DESCRIPTION

**l123** 是一款终端电子表格，它在现代公式引擎和原生 **.xlsx** 双向读写支持的基础上，重现了 **Lotus 1-2-3 Release 3.4a（1993 年）**的键盘驱动工作流。它面向那些追求经典 1-2-3 中斜杠菜单的速度与清晰感、三行控制面板以及模式驱动编辑体验的用户。

该应用支持含多个工作表的 3D 工作簿、命名范围，以及与 1-2-3 一致的公式语法（例如 **@SUM(A1..A5)**）。文件可以按 **.xlsx** 格式读写，支持 CSV 导入/导出，并计划支持只读的 **.wk3** 导入。

图表类型包括折线图、柱状图、XY 图、堆积图、饼图、HLCO 图和混合类型。输出可打印为 ASCII、PDF 或行式打印机格式。查找和替换可同时作用于公式和文本标签。

# MODES

```
READY   Default cell navigation
LABEL   Entering text content
VALUE   Entering numeric or formula
EDIT    Modifying current cell
POINT   Selecting a range
MENU    Slash menu open
```

# CONFIGURATION

运行 **l123 config --init** 可生成配置文件骨架。**l123 config** 会打印当前生效的配置。设置项涵盖按键绑定、配色主题、默认文件路径和图表默认值。

# CAVEATS

目标是忠实还原 Lotus 1-2-3 的功能，而不是像素级的视觉怀旧复刻。**.wk3** 导入为只读且仅部分实现。部分 1-2-3 宏和加载项不受支持。

# HISTORY

**l123** 是一个 Rust 项目，致力于在现代终端上复兴 Lotus 1-2-3 的交互模型。它的灵感来自 **Lotus Development Corporation** 于 **1983 年**发布的 Lotus 1-2-3——后者在整个 20 世纪 80 年代后期之前一直主导着 PC 电子表格市场，随后被 Microsoft Excel 超越。

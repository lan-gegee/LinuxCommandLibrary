# TAGLINE

显示已安装的 uv 版本

# TLDR

**显示 uv 版本**

```uv version```

**以 JSON 格式显示版本**

```uv version --output-format json```

# SYNOPSIS

**uv** **version** [_options_]

# PARAMETERS

**--output-format** _format_
> 输出格式（text、json）。

# DESCRIPTION

**uv version** 显示已安装的 uv 版本。用于验证安装和检查更新。

# INSTALL

```dnf: sudo dnf install uv```

```pacman: sudo pacman -S uv```

```apk: sudo apk add uv```

```brew: brew install uv```

```nix: nix profile install nixpkgs#uv```

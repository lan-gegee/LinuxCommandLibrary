# TAGLINE

用于生成现代 Web 应用和微服务的开发平台

# TLDR

生成新应用

```jhipster```

导入 JDL 文件以生成实体

```jhipster import-jdl [entities.jdl]```

生成实体

```jhipster entity [EntityName]```

升级 JHipster

```jhipster upgrade```

生成 CI/CD 配置

```jhipster ci-cd```

生成 Docker Compose 文件

```jhipster docker-compose```

显示信息

```jhipster info```

# SYNOPSIS

**jhipster** [_command_] [_options_]

# SUBCOMMANDS

**app**
> 生成新应用（默认）。

**entity** _name_
> 生成实体及 CRUD。

**import-jdl** _file_
> 导入 JDL 文件以生成实体。

**upgrade**
> 升级 JHipster 版本。

**ci-cd**
> 生成 CI/CD 配置。

**docker-compose**
> 生成 Docker Compose 文件。

**kubernetes**
> 生成 Kubernetes 配置。

**info**
> 显示环境信息。

# DESCRIPTION

**JHipster** 是一个用于生成现代 Web 应用和微服务的开发平台。它创建生产可用的 Spring Boot 后端，搭配 Angular、React 或 Vue 前端。开箱即用即可获得身份验证、监控、API 文档和数据库配置。

# INSTALL

```brew: brew install jhipster```

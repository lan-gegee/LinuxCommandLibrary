# TAGLINE

管理 Angular CLI 用量分析

# TLDR

**启用用量分析**

```ng analytics enable```

**禁用用量分析**

```ng analytics disable```

**查看用量分析状态**

```ng analytics info```

**提示设置用量分析**

```ng analytics prompt```

# SYNOPSIS

**ng analytics** _command_ [_options_]

# PARAMETERS

**enable**
> 启用用量分析。

**disable**
> 禁用用量分析。

**info**
> 显示当前的用量分析设置。

**prompt**
> 提示设置用量分析偏好。

**--global**
> 全局应用。

# DESCRIPTION

**ng analytics** 管理 Angular CLI 的用量分析。控制是否与 Angular 团队共享匿名使用数据，以帮助改进 CLI。

# TAGLINE

展示 ASCII 艺术动画演示

# TLDR

查看随机的 **ASCII 艺术动画**

```cacademo```

# SYNOPSIS

**cacademo**

# DESCRIPTION

**cacademo** 使用 libcaca 库在终端中播放随机的 ASCII 艺术动画。它展示了多种文本模式图形效果，可作为该库功能的演示。

演示会循环播放多种动画，包括 metaballs、matrix 特效以及其他视觉效果。

# INSTALL

```apt: sudo apt install caca-utils```

```dnf: sudo dnf install caca-utils```

```apk: sudo apk add libcaca-apps```

```zypper: sudo zypper install caca-utils```

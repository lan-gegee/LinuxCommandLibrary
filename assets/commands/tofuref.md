# TAGLINE

用于浏览 OpenTofu 提供者注册表的 TUI

# TLDR

**启动提供者注册表浏览器**

```tofuref```

# SYNOPSIS

**tofuref** [_options_]

# DESCRIPTION

**tofuref** 提供一个终端 UI，让你无需离开终端即可浏览 OpenTofu（和 Terraform）的提供者注册表。它支持集成 GitHub token 以避免速率限制，提供带 Vim 键位的键盘和鼠标导航，并支持可配置的默认值。

# HISTORY

**tofuref** 由 **djetelina** 创建，使用 **Python** 和 Textual 框架编写。

# INSTALL

```aur: yay -S tofuref```

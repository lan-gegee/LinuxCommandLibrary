# TAGLINE

终端中的 Python AST 查看器

# TLDR

**浏览 Python 文件的 AST**

```astare [my_script.py]```

# SYNOPSIS

**astare** _python-file_

# DESCRIPTION

**textual-astview** 是一款用于显示和探索 Python 抽象语法树（AST）的命令行工具。它加载 Python 源文件，在源代码旁边以交互式树的形式展示其 AST。

# HISTORY

**textual-astview** 由 **Dave Pearson**（davep）创建，使用 **Python** 基于 Textual 框架编写。

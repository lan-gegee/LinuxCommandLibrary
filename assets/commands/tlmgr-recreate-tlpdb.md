# TAGLINE

重建 TeX Live 软件包数据库

# TLDR

**重建软件包数据库**

```tlmgr recreate-tlpdb```

# SYNOPSIS

**tlmgr recreate-tlpdb** [_options_]

# DESCRIPTION

**tlmgr recreate-tlpdb** 根据已安装文件重建 TeX Live 软件包数据库。用于损坏安装的恢复工具。TeX Live Manager 的维护功能之一。

# CAVEATS

仅在数据库损坏时使用。可能无法完整恢复所有软件包元数据。

# TAGLINE

**pactrans --remove** 的便捷别名，用于移除软件包

# TLDR

此命令是 **pactrans --remove** 的别名

查看原始命令的文档

```tldr pactrans```

# SYNOPSIS

**pacremove** [_options_] _package(s)_

# DESCRIPTION

**pacremove** 是 **pactrans --remove** 的便捷别名，用于从系统中移除软件包。它通过 pactrans 事务系统提供了另一种执行软件包移除的接口。

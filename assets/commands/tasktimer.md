# TAGLINE

极简的 TUI 任务计时器

# TLDR

**启动任务计时器**

```tt```

# SYNOPSIS

**tt**

# DESCRIPTION

**tasktimer** 是一个极简的 TUI 任务计时器。输入任务描述并按 Enter 开始计时；再次按 Enter 停止计时，或输入新任务直接切换。所有任务的时长会在标题栏中累加显示。按 Ctrl+C 停止并显示汇总。

# HISTORY

**tasktimer** 由 **Carlos Alexandro Becker**（caarlos0）创建，使用 **Go** 编写。

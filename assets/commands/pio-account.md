# TAGLINE

管理 PlatformIO 账户认证

# TLDR

**登录 PlatformIO 账户**

```pio account login```

**显示账户信息**

```pio account show```

**登出**

```pio account logout```

**注册新账户**

```pio account register```

# SYNOPSIS

**pio account** _command_ [_options_]

# PARAMETERS

**login**
> 登录账户。

**logout**
> 登出账户。

**show**
> 显示账户信息。

**register**
> 注册新账户。

**forgot**
> 申请重置密码。

**-u**, **--username** _user_
> 账户用户名。

**-p**, **--password** _pass_
> 账户密码。

# DESCRIPTION

**pio account** 管理 PlatformIO 账户认证。访问 PlatformIO Registry、Teams 和远程开发功能都需要它。提供免费账户。

# INSTALL

```aur: yay -S pio```

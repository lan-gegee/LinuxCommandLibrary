# TAGLINE

AI 编程智能体的 TUI 仪表盘

# TLDR

从任意项目目录**启动**

```sidecar```

**指定项目根目录**

```sidecar --project [/path/to/project]```

# SYNOPSIS

**sidecar** [**--project** _path_] [**--debug**] [**--version**]

# DESCRIPTION

**sidecar** 是一个终端伴侣工具，与 Claude Code 和 Codex 等 AI 编程智能体并行运行。它提供分栏界面，显示 git diff、文件树、对话历史和任务管理。你可以不离开终端就规划任务、审查 diff、暂存提交和管理工作区。

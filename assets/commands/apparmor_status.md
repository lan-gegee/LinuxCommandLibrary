# TAGLINE

报告当前的 AppArmor 约束状态。

# TLDR

此命令是 aa-status 的**别名**

查看原始命令的文档

```tldr aa-status```

# SYNOPSIS

**apparmor_status**

# DESCRIPTION

**apparmor_status** 是 **aa-status** 的别名，后者报告 AppArmor 约束当前状态的各种信息。完整文档请参见 **aa-status**。

# INSTALL

```apt: sudo apt install apparmor```

```pacman: sudo pacman -S apparmor```

```apk: sudo apk add apparmor-utils```

```zypper: sudo zypper install apparmor-utils```

```nix: nix profile install nixpkgs#apparmor-utils```

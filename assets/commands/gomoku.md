# DESCRIPTION

**gomoku** 是五子棋（Gomoku）棋盘游戏的终端实现。玩家轮流在网格上落子，争取在横向、纵向或斜向连成五子。

该游戏通常与 AI 对手对弈，是一款源自日本的策略游戏。

# CAVEATS

终端游戏。需要合适的终端环境。存在多种不同的实现版本。

# HISTORY

五子棋是一种传统的策略棋盘游戏。终端版本让这一游戏变得易于上手。

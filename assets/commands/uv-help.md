# TAGLINE

显示 uv 命令的帮助信息

# TLDR

**显示常规帮助**

```uv help```

**显示特定命令的帮助**

```uv help [command]```

**显示子命令的帮助**

```uv help [command] [subcommand]```

# SYNOPSIS

**uv** **help** [_command_...]

# DESCRIPTION

**uv help** 显示 uv 命令的帮助信息。展示指定命令的用法、选项和示例。

# INSTALL

```dnf: sudo dnf install uv```

```pacman: sudo pacman -S uv```

```apk: sudo apk add uv```

```brew: brew install uv```

```nix: nix profile install nixpkgs#uv```

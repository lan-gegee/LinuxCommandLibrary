# TAGLINE

Perforce 客户端

# TLDR

**同步工作区**

```p4 sync```

**检出文件**

```p4 edit [file]```

**提交变更**

```p4 submit```

**查看变更**

```p4 changes```

**还原文件**

```p4 revert [file]```

**显示文件状态**

```p4 status```

# SYNOPSIS

**p4** [_command_] [_options_]

# PARAMETERS

**sync**
> 同步工作区。

**edit** _FILE_
> 检出文件。

**submit**
> 提交变更列表（changelist）。

**changes**
> 列出变更列表。

**revert** _FILE_
> 还原更改。

**status**
> 显示文件状态。

**--help**
> 显示帮助信息。

# DESCRIPTION

**p4** 是 Perforce 客户端。通过与中央服务器协作管理版本控制。

该工具提供企业级版本控制能力，擅长处理大型二进制文件。

# CAVEATS

需要 Perforce 服务器。商业产品，面向企业用户。

# HISTORY

Perforce 创建于 **1995** 年，是一款企业级**版本控制系统**。

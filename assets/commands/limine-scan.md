# TAGLINE

扫描 Limine 引导加载程序的安装

# TLDR

此命令是 **limine-entry-tool --scan** 的别名。

查看原始命令的文档

```tldr limine-entry-tool```

# DESCRIPTION

**limine-scan** 扫描块设备以查找现有的 Limine 引导加载程序安装，并报告其位置。它是作为 **limine-entry-tool --scan** 的便捷别名而提供的。

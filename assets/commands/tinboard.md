# TAGLINE

基于终端的 Pinboard 书签客户端

# TLDR

**启动 Pinboard TUI 客户端**

```tinboard```

# SYNOPSIS

**tinboard** [_options_]

# DESCRIPTION

**tinboard** 是 Pinboard.in 书签服务的 TUI 客户端。它让你完全在终端中管理、搜索和浏览自己的 Pinboard 书签。

# HISTORY

**tinboard** 由 **Dave Pearson**（davep）创建，使用 **Python** 的 Textual 框架编写。

# TAGLINE

显示 OpenCode 使用统计信息

# TLDR

**显示** token 用量与费用统计

```opencode stats```

# SYNOPSIS

**opencode stats**

# DESCRIPTION

**opencode stats** 显示 OpenCode 会话的 token 用量和费用统计。它展示跨不同 AI 提供商累计消耗的 token、API 调用次数以及估算费用。适合用于监控使用情况和管理 API 开支预算。

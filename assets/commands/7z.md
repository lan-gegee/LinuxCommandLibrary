# TAGLINE

支持多种格式的高压缩比文件归档工具

# TLDR

**创建归档**

```7z a [archive.7z] [files...]```

**解压归档**

```7z x [archive.7z]```

**解压到指定目录**

```7z x [archive.7z] -o[directory]```

**列出归档内容**

```7z l [archive.7z]```

**测试归档完整性**

```7z t [archive.7z]```

使用密码创建

```7z a -p[password] [archive.7z] [files]```

以最大压缩率创建

```7z a -mx=9 [archive.7z] [files]```

# SYNOPSIS

**7z** _command_ [_switches_] _archive_ [_files_...]

# COMMANDS

**a**
> 向归档添加文件

**x**
> 按完整路径解压

**e**
> 解压（扁平化，不带路径）

**l**
> 列出归档内容

**t**
> 测试归档完整性

**d**
> 从归档中删除

**u**
> 更新归档

# PARAMETERS

**-o**_dir_
> 输出目录（-o 后不加空格）

**-p**_password_
> 设置密码

**-mx=**_n_
> 压缩级别（0=仅存储，9=极限）

**-t**_type_
> 归档类型（7z、zip、tar、gzip、bzip2）

**-mhe=on**
> 加密文件名（7z 格式）

**-r**
> 递归处理子目录

**-y**
> 所有询问均自动回答 yes

**-v**_size_
> 创建分卷（如 -v100m）

# DESCRIPTION

**7z** 是 7-Zip 归档器的命令行界面，支持多种格式：7z、ZIP、TAR、GZIP、BZIP2、XZ 等。

7z 格式采用 LZMA/LZMA2 算法，提供高压缩比，通常比 ZIP 好 30%-70%。它还支持 AES-256 加密和多分卷归档。

解压支持许多额外的格式，包括 RAR、CAB、ISO 等（部分格式只读）。

# CAVEATS

7z 格式的通用支持程度不如 ZIP。如需最大兼容性，请考虑使用 ZIP。

**-o** 后不能有空格：应写 **-o/path** 而不是 **-o /path**。

创建 RAR 需要单独的 RAR 工具。7z 只能解压 RAR 文件。

分卷归档（**-v**）需要所有分卷才能解压。

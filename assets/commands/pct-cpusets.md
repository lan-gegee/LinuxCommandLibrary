# TAGLINE

打印 Proxmox LXC 容器分配到的 CPU 集

# TLDR

**打印**已分配 CPU 集的列表

```pct cpusets```

# SYNOPSIS

**pct cpusets**

# DESCRIPTION

**pct cpusets** 打印由 Proxmox VE 管理的 LXC 容器所分配到的 CPU 集列表。它是 **pct** 的诊断子命令，在检查容器进程如何被绑定或限制到主机 CPU 时很有用。

# HISTORY

**pct cpusets** 是 **Proxmox VE** 中用于管理 LXC 容器的 **pct** 工具的一部分。

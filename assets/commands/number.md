# TAGLINE

将数字转换为英文单词

# TLDR

**将数字转换为单词**

```number [42]```

**转换大数**

```number [1234567]```

**以序数词形式转换**

```number -o [3]```

# SYNOPSIS

**number** [_options_] _number_

# PARAMETERS

_NUMBER_
> 要转换的数字。

**-o**
> 以序数词形式输出。

**-l**
> 使用长级差（long scale）。

**--help**
> 显示帮助信息。

# DESCRIPTION

**number** 将数字转换为英文单词。是 BSD games 的一部分。

该工具将数值拼写为单词，适用于支票书写或教学场景。

# CAVEATS

属于 bsd-games。仅支持英语。支持的数值范围有限。

# HISTORY

number 是一个经典的 **BSD 游戏实用程序**，用于把数字转换为其英文单词形式。

# TAGLINE

简洁的 PipeWire TUI 音频混音器

# TLDR

**启动 PipeWire 音频混音器**

```wiremix```

# SYNOPSIS

**wiremix**

# DESCRIPTION

**wiremix** 是一个基于终端的 PipeWire 音频混音器，可用于调节音量、静音轨道、在设备与应用之间重路由音频，以及配置端口和配置文件。其界面克隆自 ncpamixer，而 ncpamixer 又受 pavucontrol 启发。

# HISTORY

**wiremix** 由 **Thomas Sowell**（tsowell）创建，使用 **Rust** 编写。

# INSTALL

```dnf: sudo dnf install wiremix```

```pacman: sudo pacman -S wiremix```

```zypper: sudo zypper install wiremix```

```nix: nix profile install nixpkgs#wiremix```

# TAGLINE

在存储之间移动 Proxmox 虚拟机的磁盘

# TLDR

此命令是 **qm disk move** 的别名

查看原始命令的文档

```tldr qm disk```

# SYNOPSIS

**qm move-disk** _vmid_ _disk_ _storage_ [_options_]

# DESCRIPTION

**qm move-disk** 是 **qm disk move** 的另一种形式，用于在存储后端之间移动虚拟机磁盘。提供连字符变体是为了保持兼容性。

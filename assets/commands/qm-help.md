# TAGLINE

显示 qm 子命令的帮助

# TLDR

显示指定命令的**帮助**

```qm help create```

以**详细**信息显示帮助

```qm help create --verbose true```

# SYNOPSIS

**qm help** _command_ [_options_]

# PARAMETERS

**--verbose** _true|false_
> 显示详细的帮助信息

# DESCRIPTION

**qm help** 显示 qm 命令的帮助信息。它提供所有 qm 子命令的用法说明、选项和参数描述。

使用 verbose 模式可获得更详细的解释和示例。

# INSTALL

```dnf: sudo dnf install qm```

# TAGLINE

为 Sailfish 项目应用配置补丁

# TLDR

**应用配置补丁**

```sfdk apply [patch_file]```

# SYNOPSIS

**sfdk apply** [_options_] _patch_

# DESCRIPTION

**sfdk apply** 为 Sailfish OS 项目应用配置补丁。属于用于开发 Sailfish OS 应用的 Sailfish SDK（sfdk）命令行工具的一部分。

# TAGLINE

拼接 scamper warts 文件

# TLDR

**拼接 warts 文件**

```sc_wartscat [file1.warts] [file2.warts] > [combined.warts]```

# SYNOPSIS

**sc_wartscat** _files_...

# DESCRIPTION

**sc_wartscat** 将多个 scamper warts 文件拼接为单个文件。scamper 工具集的一部分。

# INSTALL

```apt: sudo apt install scamper```

```zypper: sudo zypper install scamper```

```brew: brew install scamper```

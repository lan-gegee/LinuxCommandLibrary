# TAGLINE

终端中的 LLM token 用量监控器

# TLDR

**启动 LLM 用量仪表盘**

```toktop```

# SYNOPSIS

**toktop** [_options_]

# DESCRIPTION

**toktop** 是一个用于监控 OpenAI 和 Anthropic API token 用量与费用的终端仪表盘。它让账户管理员无需切换到 Web 仪表盘即可跟踪 LLM API 的使用情况。

# HISTORY

**toktop** 由 **htin1** 创建，使用 **Rust** 编写。

# INSTALL

```brew: brew install toktop```

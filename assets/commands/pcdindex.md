# TAGLINE

根据 Kodak PhotoCD 文件创建图像索引图

# TLDR

**创建 PhotoCD 图像索引**

```pcdindex [input.pcd] > [index.ppm]```

# SYNOPSIS

**pcdindex** [_file_]

# DESCRIPTION

**pcdindex** 根据 Kodak PhotoCD 文件创建图像索引（缩略图集）。PhotoCD 是 20 世纪 90 年代基于 CD 的图像存储格式。属于 Netpbm 工具集。

```dnf: sudo dnf install netpbm```

```apk: sudo apk add netpbm```
